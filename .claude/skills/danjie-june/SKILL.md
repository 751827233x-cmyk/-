## 〇、三层规则体系与优先级仲裁 ⚠️ 全文总纲（先读本章）

### 1. 三层规则体系
本技能所有规则分属三层，遇到表述冲突先判断所属层：

- **剧作层**：台词、剧情、拆段——管"演什么"
- **视听语法层**：轴线、景别、运镜、打光设计、节奏——管"怎么拍"
- **提示词工程层**：禁用词、字数预算、参考图、防伪影、交付排版——管"怎么写给模型"

⚠️ **关键认知**：提示词工程层的禁用词约束的是**写法**，不约束视听设计本身。
例：打光设计可以采用伦勃朗式侧光塑形（视听层成立），但提示词中不得出现"光斑"一词（工程层禁用），应换词表述为"面部一侧受光、另一侧渐变阴影"。**设计保留，换词表述。**

### 2. 全局优先级（高→低，规则冲突时高位胜出）
1. 台词完整性：三零保真（零删减、零换序、零改归属）；剧情零压缩（回忆/长动作禁梗概化）
2. 全景/定位帧禁台词
3. 空间连续性：轴线、站位锁定、屏幕方向、出入画方向、高低与距离真实性
4. 衔接连续性：动势、情绪、人物外观状态、环境道具状态
5. 提示词禁用词、字数预算与复制区纯净
6. 画幅与安全区
7. 节奏约束：段时长（含定位帧≤15秒）、单镜时长（按负载分级）、台词字数区间、时间轴核算
8. 镜头设计偏好：运镜多样性、景别丰富度、首帧换人
9. 光效风格偏好

### 3. 专项仲裁条款 ⚠️（逐条消除规则对撞）

| 冲突场景 | 仲裁结果 |
|---|---|
| 集首段：钩子帧 vs 新场景全景开场 | **钩子帧先行**（1-2镜），全景紧随其后交代空间（冷开场语法） |
| 换场景段：全景开场 vs 首帧换人 | **全景开场胜出**；首帧换人规则仅约束同场景延续段 |
| 段末定位全景 vs 结尾镜头禁全景 | 定位帧是叙事结尾镜头**之后的附加帧**，不算结尾镜头、不参与下段承接判断；**集尾段豁免定位帧** |
| 单句台词>45字且不可断、不可删 | 该段标注"超长台词段"，时长允许上浮至18秒（管线支持时）；管线不支持则在自然语气停顿处跨段接续并标注，由后期负责音频无缝拼接 |
| 动作豁免段/闪回段/定位帧 vs 台词密度底线 | 豁免，不受"每段≥2句台词"与20字下限约束 |
| 拆段四断点 vs 台词密度底线 | **断点强制性高于密度底线**——拆出的短段按短段时长规则执行，不得跨断点合并凑台词 |
| 打光设计用词 vs 禁用词表 | 设计保留，**换词表述** |
| 单人独白戏：首帧换人无人可换 | 首帧用道具/手部/背影/环境局部镜头替代 |
| 首帧换人 vs 上段末镜为多人同框（v2.4） | 末镜多人时，首帧可取其中**任一人**（优先剧情主动方）或道具/环境帧 |
| 首帧换人 vs 剧情要求末镜人物紧接开口（v2.4） | **标准解法**：该角色首句作**画外台词**压在其他角色反应镜头上作为首帧（实战验证） |
| 双人"同时说话" vs 对口型风险（v2.4） | 同框齐声仅限喊叫/尖叫类短句（≤8字，口型精度要求低）；对白长句严禁双人同步开口，改为紧咬先后的单人镜保留"几乎同时"节奏感 |
| 声音三态判定 | **画外台词=合法**：场景内角色当前时空的现场说话声；**内心OS=开关**：默认关闭、启用后合法且必须双轨绑定；**解说旁白=永禁** |
| 连续相同运镜禁令 vs 正反打定镜对切 | 正反打定镜对切合法（不同机位即不同镜头）；**运动运镜**仍不得连续同型同向 |
| 入镜必有反应 vs 远景禁微表情 | 反应颗粒度按景别分级：远景"宏观肢体势态"即合格，微表情仅特写/近景层级要求 |
| 一镜到底段 vs 切镜规则 | 用户声明的一镜到底段豁免切镜规则与单镜时长限制；轴线、状态连续、台词规则照常 |
| 文字定妆锚点 vs 无图禁外貌词 | 资产表统一定义的文字定妆词组是禁令唯一例外（全剧逐字复用、不得变体）；逐段临时编造仍严禁 |

### 4. 模型版本复审注记
工艺层规则基于当前主流图生视频模型能力设定，应随模型迭代定期复审：对口型能力提升→放宽说话景别与画外占比；多人同框稳定→放宽全景与群演缓释；多镜头时序增强→调整管线选择。

## 一、开工前置与执行流程

### 1. 执行流程总览 ⚠️ 六步SOP
```
①读本通读 → ②建全局资产表 → ③出节拍与拆段规划表（含台词对账，用户确认）
→ ④逐段产出执行稿（场记区+复制区） → ⑤每段过分级自检（🔴阻断→🟡质量）+批次复盘
→ ⑥交付（资产表+回填后规划表+全部段落+集末状态快照+对账行）
```
- ③规划先行：先定全局节奏与时长预算，避免写到一半节奏失衡推倒重来
- ⑤批次复盘：每批交付后记录规则摩擦点，供技能版本迭代
- 局部返工：单镜头生成失败时按镜头粒度重出，不牵连整段

### 2. 画幅声明 ⚠️ 开工必须先定
- **默认 9:16 竖屏**（用户声明横屏则按 16:9 执行，并恢复横屏语法）
- **竖屏构图规范**：
  - 单人构图优先，人物占画面主导
  - 纵向三层调度：前景元素压底边 / 人物中层 / 环境顶层——**用纵深替代横向调度**
  - 头顶留白适度，避免大面积空顶
  - **对话戏用单人正反打，不用过肩**；可用前景虚化肩影暗示对方存在
  - **安全区**：画面右侧边缘约15%（互动按钮区）、底部约20%（字幕/进度条区）——人脸、手部关键动作、关键道具避开
- 16:9 横屏时：恢复过肩镜头、三分法、横向调度等横屏语法

### 3. 全局资产表 ⚠️ 每个项目开工输出一次
开工先建表，后续每段只引用ID，不重复描述：

```
【角色表】角色ID | 姓名 | 性别 | 音色描述 | 打光缺省方案
  └ 造型变体：造型ID(A/B/C…) | 一致性锚点：参考图(有/无) 或 文字定妆词组 | 适用场次范围
【场景表】场景ID | 名称 | 内/外景 | 主光源清单 | 主光方向(画左/画右/顶/背) | 色温基调
  └ 时段变体：时段ID(日/夜/黄昏…) | 参考图(有/无) | 光线状态
【道具表】道具ID | 名称 | 归属角色 | 参考图(有/无)
【全局开关】内心OS：关(默认)/开 ｜ 闪回编码：色温偏移/降饱和(二选一) ｜ 风格：写实(默认)/其他
```

- **文字定妆锚点**：无参考图的角色/场景，可在资产表定义**固定外貌/服装/场景锚定词组**（每项30-60字、精炼），由用户提供或经用户确认后从剧本提炼；启用后**全剧逐字复用、不得改写变体**——这是"无图禁外貌词"禁令的唯一例外，逐段临时编造仍然严禁
- **一致性锚点优先级：参考图 > 文字定妆词组 > 无（无则不写外观）**
- **造型变体**：换装必须有剧本支撑，每段引用"角色ID-造型ID"，同场次内锁定不得漂移
- **时段变体**：同场景昼夜按时段ID区分，时间跳跃按换场处理
- 场景表的主光源清单与主光方向是打光设计依据（见第十一章）
- 音色在角色表定义一次，段内不再重复

### 4. 节拍与拆段规划表 ⚠️ 逐段产出前必须先出
```
【节拍规划表】集数 | 段号 | 一句话内容 | 段类型 | 负载判定 | 时长预算 | 场景ID-时段 | 出场角色-造型 | 钩子/反转/卡点标记
【台词对账】原文台词共X句、Y字（不含标点）
```
- **集时长预算**：默认单集成片60-120秒≈5-8段（按用户平台要求调整），先分预算再写稿
- **台词对账（v2.4新增）**：规划表附原文台词总句数与总字数基线；**每批交付附对账行**——已分配至各段的句数/字数与原文差额必须=0，缺一句即三零保真违规
- **回填义务（v2.4新增）**：逐段实算后将实际时长回填规划表；发生拆段/重编号时**必须重发规划表并标注变更行**，段号不得静默复用
- 全剧反转点、情绪顶点、付费卡点标记完毕后再逐段执行；规划表建议用户确认后批量产出

### 5. 参考图与定妆优先级
**参考图 > 文字定妆词组 > 用户场景要求 > 无（无则不给外观/场景词）**
- 有参考图：按图实际画面描述，不得编造图中未呈现内容
- 有文字定妆：逐字引用锚定词组，不得变体、不得扩写
- 有场景要求无图：严格按要求生成，不添加未提及元素
- 都没有：只写动作、情绪、运镜、光效、空间关系
- ⚠️ **剧本中的服装/长相描述不得逐段直接引用**——但可作为建立文字定妆词组的素材（须经用户确认固化进资产表）

### 6. 生成管线声明
- **默认管线**：图生视频，一段=一条提示词（含多镜头时序），首帧图=段首镜头静帧
- **分条管线**：每镜头单独成条，首尾帧接力；段级规则仍跨条生效
- **段间接力**：同场景延续段，上段末帧（或定位帧）作为下段首帧图的空间参考底图

## 二、剧作层：场次、拆段与台词

### 1. 场次规则 ⚠️
- 一切按剧本场次和场景来，**一段只属于一个场次**
- 场次/场景切换必须同步拆段，**不允许自行更改剧本场景设定**（剧本正文与小标题冲突时以正文动作逻辑为准，并向用户说明地理解法）
- **同场景内时间跳跃**按换场处理：拆段 + 时段变体 + 光线同步更新 + 后期备注时间转场
- **平行剪辑**：按线分段交替输出，每条线独立遵守轴线、站位、状态连续

### 2. 拆段四断点 ⚠️（优先切分依据）
拆段以四断点为**优先依据**，约200字一段降为辅助参考。触发任一断点必须切分新段：
1. **时空跃迁断点**：空间改变或时间流逝——即场次规则
2. **微目标转换断点**：角色核心动机突变（试探戏突变遇袭戏）
3. **阵营变动断点**：能改变权力压迫关系的关键角色入场或离场
4. **情绪沉降断点**：激烈对抗/情绪爆发后的余韵沉降期结束即段完结

### 3. 拆段基础规则 ⚠️ 台词三零保真（v2.4强化）
- 按剧情完整拆段，**台词三零保真：零删减、零换序、零改归属**——台词内容、句子先后顺序、说话人归属一律不得改动（实测曾发生"先发制人"双方被倒置，自此列为阻断项）
- **剧情零压缩**：回忆、前史、长动作段落禁止压缩成一句话梗概，必须完整拆解为镜头序列
- 优先保证：台词不断裂、词气不断裂、动作承接不断裂、情绪落点不断裂
- 不允许为了凑字数硬拆完整表达

### 4. 台词整合规则
- 单句超30字 → 按两句整合为一段；单句低于30字 → 按三句整合为一段
- 前提：不断裂台词、不破坏完整表达、不拆散与台词紧相连的动作和情绪

### 5. 台词字数规则 ⚠️（以15秒为单位）
- **每15秒台词不超过45字、不低于20字**（不含标点；启用内心OS时OS计入）
- 换算依据：中文常速约4.5字/秒，45字≈10秒台词，留足反应与气口；20字下限防凑时长
- **比例折算（v2.4新增）**：短于15秒的段按比例折算判定——**字数÷段秒数×15 须在20-45区间**，统计注明折算式（如：台词23字/11秒，折合15秒≈31字 ✓）
- **拖长音上浮（v2.4新增）**：喊叫/尖叫/哭腔/拖长音台词，发声时长按基准×1.3-1.5上浮，核算表注明
- **语气词判定（v2.4新增）**：单字语气词（嗯/啊/哼等）计入字数、**不计入句数**；段内仅有语气词时按"仅1句"档时长规则执行（≤6秒、≤3镜）
- 绝不删减原剧本台词——超标必须拆段；单句>45字无法拆分 → 按仲裁条款处理（超长台词段）
- 拆段后附注字数统计；豁免：动作豁免段、闪回段、定位帧不受20字下限约束

### 6. 闪回规则 ⚠️
- 遇"闪回"→ **必须单独成段**，标注【闪回段】
- **三明治闭环**：现实 → 闪回 → **必须切回现实**，切回后精准衔接角色因回忆产生的情绪突变或动作前摇
- **闪回分型时长**：情绪闪现型（模糊面容/一句话）=1镜1-2秒瞬间切回；叙事交代型（恩怨前史）=划拨足够时长、闪回内切2-3镜完整叙事，禁止梗概化
- **闪回完整性一票否决**：跨生成批次时闪回必须完整包含在同一批次内
- **闪回视觉编码**：全剧统一一种标记（色温偏移或降饱和，写入资产表），进出闪回直接切（可配回声音桥），白闪慎用；闪回内部照常遵守轴线与连续性
- 闪回段豁免台词密度；无台词闪回按纯动作段控制（≤4秒，≤2镜）

### 7. 台词密度底线 ⚠️
- **每段至少2句台词**（豁免段除外；语气词不计句）
- 仅1句台词 → 总时长≤6秒，镜头≤3个；纯动作/无台词段 → ≤4秒，≤2镜（动作豁免段除外）
- 补足方式：①合并相邻短段 ②拆段时将有台词的相邻内容归入同段（不得跨四断点合并）

### 8. 动作戏豁免条款 ⚠️
- 打戏/追逐/坠落/仪式等无台词动作段：允许 6-15 秒、2-8 个镜头（极高负载允许0.5-2秒急切），不受台词密度约束
- **必须写出动作编排**：招式过程/攻防节奏/受击反应/环境互动，不允许"两人打斗"一笔带过
- **反穿模借位剪辑（肢体接触强制执行）**：
  - **接触瞬间规避法**：镜头A发力起势（身体接触前切出）→ 直接切 → 镜头B受击结果（踉跄/倒飞/环境破坏），严禁单镜完整呈现持续肉搏接触
  - **前景遮挡借位**：尘土、门框、栏杆、衣摆、光效遮挡易穿模接触区；遮挡物不得改变主空间关系
- **涟漪效应**：大场面/大招/重击段落，至少30%镜头给"环境破坏反馈"或"旁观者惊恐反应"
- 跟拍、急推急拉、环绕在动作豁免段解禁为主力；动作豁免段前后必须有台词段衔接

## 三、空间系统：轴线、方向、站位、视线 ⚠️ 核心章节

### 1. 轴线规则（180°规则）
- **每场戏开场即建轴**：以核心两人连线（对话戏）或运动方向（动作戏）为轴，**全场机位锁定一侧**
- **每镜标注屏幕方向**：人物位于画左/画中/画右 + 面朝画左/画右
- 对话正反打方向锁定：A居画左面朝画右 ↔ B居画右面朝画左，全场不变
- **越轴管理**：仅可通过①沿轴中性镜头②人物走位带轴③无方向性插入镜头三者之一过渡，禁止硬越轴
- **30°规则**：同一主体直接相切的两镜，机位变化≥30°或景别变化≥一级
- **AI落地写法**：提示词明确写"XX位于画面左侧、面朝画面右侧"，每镜必写

### 2. 多人戏轴线与群演
- **三人以上**：核心冲突双方连线定主轴，第三方固定区域后按副轴处理；单人反应插入镜头维持其在主轴侧的既有朝向
- **群演崩脸缓释**：背景群演不给正脸——虚化、背影、肩部以下、远景化任选；人数在段落标注；群演不参与轴线计算但行动方向感一致
- 群演表情降级：远景群演只需姿态符合氛围

### 3. 运动方向与出入画
- **出入画方向匹配**：出画左 → 下一镜从画右入画；违反即空间跳变
- **行进方向锁定**：走路/追逐全程屏幕方向锁定，换向必有转弯镜头或中性镜头过渡
- 入画=登场、出画=离场留空；段落有出入画必须在轴线栏记录方向供下段承接

### 4. 视线匹配、POV与机位高度
- **视线匹配剪辑**：人物看向画外某物 → 下一镜接所看对象（POV或客观插入），对象空间方位与视线方向一致
- **POV规范**：POV前必须先有"看的人"镜头建立；POV内不出现看者；POV后通常回接反应
- POV是特写禁令的合法补充（看信/看手机/看伤口/看远处来人）
- **机位高度=视线高度**：对话戏机位默认取人物眼高；俯仰偏离必须是权力关系表达
- **权力反转律**：局势瞬间逆转时，仰俯角必须在下一镜同步反转

### 5. 位置锁定规则
- **所有人位置锁定**：每段站位与上段末尾完全一致；位置变化必须有剧本动作支撑
- 走位必须精确写出新位置，下段首帧与空间关系栏精确承接；**后退半步也算位置变动**
- 低位起身后必须精确写出站起后位置，后续严格连续承接

### 6. 站位描述要素（九要素）
每段必须写清：
1. 横向：左侧 / 中间 / 右侧
2. 纵深：前景 / 后景
3. 中轴关系
4. **高低关系**：站/跪/坐/倒地/高台/楼上楼下/空中——谁高谁低
5. **绝对距离**：双方相隔约X米/X步（贴身0-1米/中距2-5米/远距10米以上）
6. **遮挡关系**：谁被门框/栏杆/人群/烟尘等部分遮挡（无则写"无遮挡"）
**不允许写"同上站位"、"站位不变"**

### 7. 空间真实性原则 ⚠️
- **严禁为了台词更清楚、表情更好读、画面更"好看"，擅自压缩真实距离、抹平高低差、改变遮挡关系，或把远处/高位/背景层目标拉入前景**
- 使用特写/长焦/浅景深时，必须补写一句空间确认（"XX仍在远处高台上，未靠近"）
- **垂直交互重载**：压制、悬吊、踩踏、背负等零距离垂直接触时，空间描述改写为**受力点相对关系**（"从上方死死扣住"），**禁用"同层/同一平面"表述**；体型悬殊交互时，小体型方的空间参考锚定在巨物的具体接触部位

### 8. 视线关系位
每段必须写：
- 角色A看向谁、角色B看向谁、是否对视、视线是否对上（与轴线方向一致）
- **游离视线落点**：回避/心虚/傲慢/沉思等不对视情形，必须声明视线具体落点（"视线垂向右下方地面"）
- **高低差对视**：双方存在高低差时强制标注仰视/俯视
- **视线跟随**：被注视目标移动时，注视者声明"头部与目光伴随目标移动"

### 9. 动势衔接规则 ⚠️
- 姿态变化必有过渡过程（坐→站写"撑桌起身"），禁止跳变；变化前有动势铺垫
- **前后段动势丝滑衔接**：下段首帧姿态/动作方向/朝向严格承接上段末帧
- **自检**：写完每段回顾上段末帧，确认匹配无割裂

## 四、人物与环境状态、表演

每段必须补：实际出场人物（含造型ID）/ 人物特殊道具（哪只手）/ 姿态状态 / 情绪状态（动作服务情绪）

### 站桩禁止与反应分级 ⚠️
- **绝对不允许站桩式念台词**；说台词必须伴随手部动作和表情变化，台词挂在动作和情绪上
- **入镜必有反应**——颗粒度按景别分级（见第五章粒度分级）
- **焦外角色休眠**：在场但非焦点的角色，每镜保留一句宏观行为锚点做空间占位，严禁拆解其五官表情
- 避免死脸：旁观者表情与场景氛围一致（群演按降级规则）

### 表情过程化规则 ⚠️
- **表情必须写成变化过程，不是静态结果**：优先用"先……随后……说到某词时……说完后……"的过程结构
- **必须绑定触发点**：表情变化由具体事件触发（听见某句话/看见某动作/意识到某事实）
- **禁止抽象情绪标签**："愤怒地"等括号提示不得替代表情描写，必须落到具体生理细节
- 描写粒度严格服从景别分级；字数紧张时优先保过程结构、删形容词

### 人物外观状态连续性 ⚠️
- 湿身、出汗、流血、泪痕、泥污、破损等状态从发生起**全程保持**，直到剧本明确消除动作
- 每段道具姿态栏复述持续中的外观状态

### 环境与道具状态连续性 ⚠️
- 雨雪、烛火、翻倒桌椅、碎裂花瓶、洒落水渍等环境状态同样全程连续，每段场景栏复述
- **道具交接**：拿起/放下/递接尽量单镜头内完成；跨镜则两侧严格标注道具位置与持有手
- 杯中水位、信纸折痕等关键道具微状态同样追踪

### 情绪衔接规则 ⚠️
- 同场次情绪全程连贯递进，转折必须有剧本支撑；旁观者情绪与场景一致
- **前后段情绪丝滑衔接**：下段首帧严格承接上段末帧情绪落点；**过渡必有载体**（台词/动作/表情/呼吸）

## 五、节奏、负载与景别

### 1. 负载分级 ⚠️（绑定镜头时长）

| 负载等级 | 触发条件 | 单镜时长 | 策略 |
|----------|----------|----------|------|
| 极高负载 | 近身肉搏接触 / 3人以上同框 / 复杂特效巨变 / 复杂环境大全景 | **0.5-2秒** | 高频急切掩盖穿模（动作豁免段内） |
| 中负载（默认） | 2人对峙 / 带位移交互 / 常规对话 | **2-4秒** | 默认节奏 |
| 低负载 | 单人静止情绪戏 / 空镜 / 极简对话 | 2-4秒，情绪长镜可放宽至6秒 | 长镜呼吸感，禁止凑时长 |

- **段时长口径（v2.4明确）**：**段总时长含站位定位帧≤15秒**——定位帧触发时叙事部分≤13秒；超长台词段≤18秒同理含附加帧
- 反应/插入镜头1-2秒例外照旧；负载越高切镜越密——高频切镜是掩盖AI物理穿模的主动手段

### 2. 时间约束与时长核算 ⚠️
- 段时长参考梯度：1句台词→4-6秒2-3镜 / 2句→6-8秒3-4镜 / 3-4句→10-12秒4-5镜 / 台词多→12-15秒5镜 / 动作豁免段→6-15秒2-8镜
- **时长双轨核算**：单镜时长 = **MAX(台词时长, 动作时长, 运镜时长, 特效时长)**（并行时）；动作有先后因果则**串行累加**；禁止凭感觉估算
- **动作真空期补帧（反站桩核心）**：镜头时长由台词决定而动作提前做完时，真空期必须用待机微动作填满（持械警戒、胸口起伏、眼神游移、汗水滑落）；提示词中禁止留动作真空
- **时间轴核算**：分秒区间首尾相接、无重叠无空洞、总和=段时长、台词秒数与字数换算相符
- **⚠️ 核算显式输出义务（实测防偷懒闸门）**：每段必须随稿输出紧凑【时长核算表】，逐镜列出计算式——台词字数÷语速、动作链各项耗时、并行取MAX或串行累加的取值依据；**只给时间码不给推演过程=自检不合格，不得出稿**
  - 语速基准：常速4.5字/秒、爆发喊话5字/秒、虚弱/哽咽3.5字/秒；句首情绪前摇0.3-0.5秒；拖长音/尖叫×1.3-1.5上浮
  - 动作基准：瞬发动作0.5-1秒、常规交互1.5-2.5秒、慢速细节3-5秒、常速步行约1.3米/秒
  - **切镜省略原则**：位移与过程的中段可用切镜省略（电影时间压缩的唯一合法手段）；但**单个镜头内部的时间必须物理真实**，不得把串行动作压进装不下的秒数
  - **互斥动作条款**：说话与占用口部的动作（呲牙/咬牙/喝水等）不得并行，必须串行累加
- 禁止长镜头：连续相同运动运镜=视觉长镜头，必须避免

### 3. 景别规范 ⚠️
- 常规景别：全景 / 中景 / 中近景 / 近景
- **说话期间禁止胸部以上特写（对口型规避）——硬规则**（情绪贴脸用"听者特写+画外台词"方案）
- **条件许可面部特写**：非说话时刻 + 有定妆锚点 + 情绪爆点，三条同时满足 → 允许，每段≤1个，1-2秒
- 无定妆锚点角色：维持禁特写；眼睛/嘴巴大特写：高风险选项，仅强参考图+情绪顶点时使用

### 4. 景别-细节粒度分级 ⚠️（光学可见度法则）

| 景别（物理距离） | 表情粒度 | 物理细节粒度 | 台词处理 |
|------|----------|----------|----------|
| 远景/全景（>5米） | **禁器官级微表情**——强制宏观肢体势态（躯干紧绷/踉跄后退/阵型变化） | 环境级（地形/气浪/建筑/天色） | 不写口型喉结——"伴随远处的怒吼声（台词），人物挥臂" |
| 中景/中近景（2-5米） | 眉眼轮廓+大致嘴型，禁瞳孔/毛孔级 | 中观级（衣摆撕裂/碎石飞溅/武器光晕） | 常规出镜说话（最小近景规则照旧） |
| 近景/特写（0-1米） | 全量微表情（瞳孔/咬肌/喉结/汗珠） | 微观级（血丝/火星/尘粒/布料纹理） | 出镜说话或听者特写+画外 |

- 这同时是**字数预算优化器**：远景省下的微表情字数投给动作与空间
- "入镜必有反应"的判定随分级执行

### 5. 空镜规范（B-Roll）
- **定义**：无人物出现的纯环境/物体镜头（空镜≠全景——全景有人物站位；空镜不受全景规则约束，**可承载画外台词与环境音**）
- **三大用法**：①开场氛围铺垫 ②剧烈情绪爆发后的缓冲（2-3秒沉降）③结尾留白余韵/暗示时间流逝
- 时长2-4秒，必须有动势（光影移动/风吹/雨落/烛火摇曳）
- 段总时长<10秒可省略；情绪爆发段建议必配

### 6. 焦段表

| 景别 | 推荐焦段 | 说明 |
|------|----------|------|
| 全景/定位帧/空镜 | 24-35mm | 空间交代 |
| 中景 | 35-50mm | 调度主力 |
| 中近景 | 50-85mm | 对话主力 |
| 近景 | 85mm | 压缩背景、浅景深 |
| 面部特写（条件许可） | 85-105mm | 必须背景虚化 |

- 广角贴近人物产生畸变，仅用于压迫/眩晕/失衡的刻意表现

### 7. 景别丰富度
- 必须多景别，避免连续相同景别；变化有逻辑并遵守30°规则

## 六、镜头与运镜 ⚠️ 核心章节

### 1. 切镜规则 ⚠️
- **切镜头直接切，绝不用运镜切换**；运镜仅作用于单镜头内部
- 禁止：❌甩镜切 ❌推进切 ❌拉远切 ❌平移切
- **切点选择**：跨条生成慎用"动作中切"，优先动作完成点或反应点切；同条生成内可用动作顶点切（动切动）；肢体接触类强制用"接触前切出→受击结果"
- 场次间默认直接切；匹配剪辑建议写后期备注

### 2. 一镜到底段 ⚠️（用户声明触发，慎用）
- 用户明确要求时，该段标注【一镜到底段】：豁免切镜规则与单镜时长限制——段内不切镜，用连续运镜组合调度；段时长≤单次生成上限；轴线、状态连续、台词规则、禁用词照常生效
- ⚠️ 漂移风险高：避免复杂多人交互与肢体接触；未声明时一律按默认切镜逻辑

### 3. 动势原则 ⚠️
- **每镜必须有动势**——镜头运动或画内主体运动至少其一
- **定镜许可**：定镜+明显画内动势=合法（对峙僵持/权威/压迫/惊愕定格/正反打对切）；全篇≤30%、对话段≤50%
- **绝对禁止：定镜+人物静止无表演=冻结帧**（真空期补帧规则同时兜底）

### 4. 运镜分级
- **主选**：左右平移 / 缓慢推进 / 拉远 / 定镜+画内动势
- **辅助**：旋转摇上、旋转摇下（每段≤1次、≤匀速，留给情绪转折）、升降、半环绕、跟拍、急推/急拉、纵深推进、低角度、俯拍
- **慎用**：全环绕；**禁止**：甩镜
- **多样性**：连续两镜不得相同运动运镜（正反打定镜对切豁免）；单一方式参考上限40%；运镜以"表达什么"为准，禁机械轮换

### 5. 运镜术语表（统一用词）
| 术语 | 定义 |
|------|------|
| 推进 | 镜头向前推近，聚焦人物上半身/手部/关键道具 |
| 拉远 | 镜头向后拉开，露出更完整空间 |
| 升镜/降镜 | 镜头垂直缓慢上升/下降 |
| 旋转摇上 | 从低位边缓慢旋转边向上摇起（情绪升华/觉醒/登场） |
| 旋转摇下 | 从高位边缓慢旋转边向下摇落（情绪沉落/压迫递增） |
| 左/右平移 | 画面匀速水平横移 |
| 斜向滑动 | 沿斜上/斜下角顺滑滑动 |
| 半环绕 | 围绕人物缓慢环绕约30° |
| 全环绕 | 360°环绕（AI极易崩，慎用） |
| 跟随跟拍 | 贴身跟随人物移动 |
| 侧面跟拍 | 侧面平行跟随 |
| 纵深推进 | 沿通道/纵深线向前推进 |
| 低角度贴地 | 贴地面低角度拍摄 |
| 俯拍 | 高位向下俯拍/上帝视角 |
| 组合运镜 | 推进转摇上、拉远转升镜、平移转推进等（一镜到底段主力） |
| 氛围运镜 | 前景遮挡推进、逆光勾边推进、雾中推进 |
| 穿梭运镜 | 穿窗镜头、回廊穿梭 |

### 6. 运镜配合情绪与台词 ⚠️
- 情绪递进→运镜加速或推进；沉落→放缓或拉远；台词节奏与运镜速度匹配
- **镜头语言对照**：推进=压迫聚焦 / 拉远=疏离释然 / 升镜=升华 / 降镜=沉重 / 平移=流动 / 急推急拉=爆发 / 定镜=凝滞威压 / 入画=登场 / 出画=离场留空
- **蓄水与破堤**：冲突爆发前用长镜/定镜拉出死寂稳态蓄压；爆发瞬间零预警直接切入急切短镜，禁止转场铺垫
- **降维压迫**：力量碾压时强者用极静长镜/定镜，弱者用极动挣扎碎切，以静衬强
- **长短阵型声明**：每段标注节奏阵型（如"长-短-极短-长"），用镜头长短排列外化情绪律动，禁止均质平分（阵型属场记信息，不入复制区）
- 每个运镜选择必须能回答"这个运镜在表达什么"

### 7. 运镜场景对照表

| 剧情场景 | 推荐运镜 | 速度 |
|----------|----------|------|
| 交代环境/空间关系 | 全景缓推、俯拍、升镜拉远 | 缓慢 |
| 氛围铺垫/情绪酝酿 | 缓慢推进、左右平移、定镜+画内动势 | 缓慢 |
| 紧张对峙/冲突升级 | 定镜凝滞（蓄水）、推进、平移 | 匀速至快速 |
| 动作场面/情绪爆发 | 跟拍、急推、碎切（破堤）、环绕（豁免段） | 快速 |
| 对话交流 | 单人正反打+微平移或定镜、缓慢推进、反应镜头 | 匀速 |
| 高潮/逆转 | 急推、急拉、旋转摇上（每段≤1次）、仰俯反转 | 快速 |
| 结尾收束/留白 | 缓慢拉远、定镜+画内动势、空镜 | 缓慢 |
| 单人独白/内心戏 | 缓慢推进、微平移、定镜 | 缓慢 |
| 人物出场 | 推进、纵深推进、低角度、入画 | 匀速 |
| 力量碾压 | 强者极静长镜 vs 弱者极动碎切 | 对比 |

### 8. 运镜速度标注
格式：`运镜方式（速度）`——缓慢/匀速/快速；旋转类≤匀速
- **速度与时长匹配**：缓慢运镜需≥3秒镜头；0.5-2秒短镜只配微动、定镜或急推急拉

### 9. 气口与声桥 ⚠️
- **留1秒气口**：最后一句台词后留≥1秒画面延续，不卡尾帧
- 声桥提示（可选后期备注）：J-cut / L-cut

### 10. 每条运镜必须包含
景别（焦段）/ 运镜方式（速度）/ 构图 / 镜头语言（表达什么）/ 表情情绪（按景别粒度）/ 动作 / 屏幕方向与视线 / 台词呈现方式 / 空间关系（含高低与距离）
- ⚠️ 复制区内全部用自然语言表达：台词呈现写成"他开口道""画外传来她的声音"，（出镜/画外/OS）括号标注仅用于场记区剧本内容栏

### 11. 构图类型（按画幅适配）
- 竖屏主力：纵深引导线、前景压边、高低位压迫、中心压迫、人物偏置、上下分层
- 横屏补充：对角线、三分法、左右对峙、过肩
- 镜面构图见高危清单"镜位视角"标准解法

## 七、全景与站位定位帧

### 1. 全景禁台词 ⚠️ 绝对规则
- 全景/定位帧中不允许任何角色说话、OS、VO、画外台词——所有人声通道静默（环境音除外）
- 台词未说完先完成台词再出全景（空镜≠全景：空镜无人物，可承载画外台词）

### 2. 新场景全景开场
- 新场景首次出现必须全景开场（集首段钩子帧例外：钩子先行、全景随后）
- **多人全景崩脸缓释**：背影机位/高机位俯拍/剪影/拉开距离，避免多人正脸全景

### 3. 站位定位帧 ⚠️
- 叙事结尾镜头**之后的附加帧**，≤2秒，无台词，轻微运镜或画内动势
- 触发：①第一段结尾 ②位置/姿态/方向变化的段末 ③无变化不出
- 豁免：集尾段；性质：不算结尾镜头、不参与首帧换人判断；同样适用崩脸缓释
- ⚠️ 计入段总时长（含定位帧≤15秒）

### 4. 推进剧情的全景
- 展示走动/位移过程时允许，**必须搭配运镜**，纯静止全景不得推进剧情

## 八、首帧与结尾镜头

### 1. 首帧优先级（取第一个命中项）
1. **集首段** → 钩子帧（承接上集末状态快照）
2. **新场景段** → 全景开场（含崩脸缓释）
3. **同场景延续段** → 换人：上一段叙事结尾镜头人物**以外**的角色；**末镜为多人同框时可取其中任一人（优先剧情主动方）**
4. **单人戏** → 道具/手部/背影/环境局部替代
- **换人×台词冲突标准解法（v2.4）**：剧情要求上段末镜人物紧接开口时，其首句作**画外台词**压在其他角色反应镜头上作为首帧
- 首帧即图生视频种子帧，必须精确（人物、姿态、屏幕方向、景别、光效）

### 2. 结尾镜头规则
- **叙事结尾镜头禁全景**；可以是中景/中近景/近景/道具/反应/环境局部/空镜
- 服务下段承接；下段首帧不得从该人物开始（同场景延续时）
- 集尾段：结尾镜头=悬念帧

## 九、反应镜头与台词上镜策略

### 1. 反应镜头规则
- 人物说话时必须给其他重要角色反应镜头；重点情绪台词处必须给反应
- 入镜必有反应（粒度按景别分级）；反应镜头近景/中近景为主，1-2秒，配运镜或画内动势
- 所有人说话不正对镜头；可正面、侧面、背面拍摄
- **齐声规则（v2.4新增）**：双人同框齐声仅限喊叫/尖叫类短句（**≤8字**，口型精度要求低）；对白长句严禁双人同步开口，改为紧咬先后的单人镜保留"几乎同时"节奏感

### 2. 台词上镜策略 ⚠️（对口型风险管理核心）
每句台词标注呈现方式（标注仅用于场记区）：
- **出镜说话**：说话者画内开口（需对口型）——最小近景；重要情绪台词、宣言、对峙台词优先出镜
- **画外台词**：说话者暂不在画内，台词压在**听者反应镜头/空间镜头/空镜**上——完全规避对口型；信息过渡型台词优先画外；复制区写法："画外传来XX的声音：……"
- **内心OS（开关默认关）**：启用后合法。标注[角色X-内心OS]；属于角色当下内心声音，≠解说旁白；**双轨绑定强制**——OS响起时画面必有该角色对应生理反应/微表情；OS无对口型风险，可压在本人任意景别镜头上（全景/定位帧除外）；OS计入台词字数；建议每段≤2句
- **无台词**：纯反应/动作/定位/空镜
- **画外台词+OS合计占比≤50%（按字数计）**；爆点台词必须出镜说
- "听者特写+画外台词"=情绪贴脸时刻的合法组合
- 全景/定位帧禁一切人声（含画外与OS）

## 十、集级结构与跨集管理

分镜层的钩子责任=**选帧**：开场选最强画面、结尾选最吊画面。
- **集时长预算**：单集60-120秒≈5-8段，规划表先行分配，实算后回填
- **集首段**：第一镜=钩子帧，允许冷开场（钩子先行、全景随后）
- **集尾段**：结尾镜头=悬念帧；禁全景、豁免定位帧
- **付费卡点**：按集尾段标准执行
- **集末状态快照**：各角色位置/姿态/情绪/外观/造型ID+场景环境状态，供下集承接
- 未分集时按单集处理

## 十一、光效与打光

### 1. 打光决策顺序 ⚠️
**第一步：光源动机**——查场景表主光源清单，主光方向/性质必须能被场景内光源解释，提示词写明光从哪来
**第二步：情绪反差**——冲突=硬光高反差 / 温情=柔光低反差 / 审判压抑=顶光 / 恐惧=低位光 / 悬疑=侧光分割
**第三步：缺省方案**（无明确依据时）——男性=侧光塑形（写"面部一侧受光、另一侧渐变阴影"，⚠️不写"三角光斑"）；女性=柔和顶前光（写"正面柔光、面部立体柔美"）；悲情/惊悚戏按情绪反差打光，不得机械套用美颜光
**第四步：轮廓光**——近景/中近景/氛围镜头默认侧逆光勾边，前提是存在可解释背光源；不成立改用色彩分离/景深分离
**第五步：阴影补光自检**——人物处于背光/阴影/俯卧位而剧情需要面部可读时，提示词必须补"环境漫反射补光/微弱辅助底光"，禁止阴影里凭空清晰

### 2. 光位锁定 ⚠️
- 主光方向同场次锁定（窗在画左则全场主光从画左来），正反打两侧受光面服从同一光源逻辑
- 光位变化必须有剧情支撑（开灯/熄烛/日落），变化后重新锁定并标注

### 3. 色温规则
- 同场次色温统一；场次间转变走过渡段；逆光色温与主光一致

### 4. 题材冷暖光对照表

- 每段基调必须写清：光影重点/空间气氛/情绪主色/镜头任务/打光方案（动机→反差→缺省）/主光方向/色温/近景勾边方式

### 2. AI高危画面回避清单 ⚠️

| 高危内容 | 风险 | 回避方案 |
|----------|------|----------|
| **镜子戏（照镜/穿衣镜/洗手台镜）** | 反射崩坏 | **标准解法=镜位视角（v2.4实战验证）**：摄影机置于镜面位置直拍人物正面，画面不含镜框与反射，"照镜"语义由人物视线与整理动作表达；镜框必须入画时反射区虚化或只取局部；严禁"人物+清晰镜像"双人同框 |

| 多人正脸同框 | 崩脸 | 背影/高机位/剪影/远景化 |
| 密集手部精细交互（数钱/弹琴/系扣） | 手部畸变 | 局部特写带过、动作简化、借位 |
| 持续肢体接触（肉搏/拖拽/勒颈） | 物理穿模 | 接触前切出→受击结果+前景遮挡借位+极高负载急切 |
| 复杂道具交接 | 道具漂移 | 单镜头内完成交接 |

### 3. 字数预算 ⚠️
- **1900字上限只计复制区正文**：画面视觉基调（含光效词组）+分秒镜头序列+特效提示词（文字定妆词组随引用计入）
- **不计入**：全部场记区信息——场景/轴线/站位/视线/道具姿态栏、剧本内容、节奏阵型、时长核算表、台词对账、音效建议、统计注记、后期备注
- 景别粒度分级是天然的字数优化器

### 4. 复制区/场记区分离 ⚠️ v2.4交付排版强制（实测防误投喂）
- **复制区**（直接投喂视频模型，独立代码块）：画面视觉基调 + 分秒镜头序列 + 站位定位帧（如触发）+ 特效提示词
  - 区内**禁止出现**：时长核算表、节奏阵型、[光效]标记、（出镜/画外/OS）括号标注、栏位名、任何场记术语——全部为自然语言画面描述
- **场记区**（人看，不投喂）：段落标记、场景、轴线、站位、视线、道具姿态、首帧说明、剧本内容（含台词四态标注与字数统计）、节奏阵型、时长核算表、音效建议、后期备注
- 两区必须物理分隔排版，复制区单独成块，杜绝场记信息混入生成提示词

### 5. 交付物性质声明
- 成品执行稿=**干声纯画面执行稿**：无字幕、无BGM、无解说旁白
- 这是交付物规格——BGM、台词字幕由后期统一添加，生成画面内不得自带

## 十三、声音与特效

### 1. 特效提示词
- 特效服务剧情，与动作、环境反馈、镜头同步，写成可视化内容；粒度遵守景别分级

### 2. 音效建议（与运镜联动）
- 环境音 / 动作音 / 道具音 / 特效音 / 情绪增强音；音效节奏与运镜速度匹配
- **音效张力三件套**：静音真空（冲击画面前0.5秒抽空所有声音）/ 重音卡点（切入瞬间极重低频砸下）/ 听觉反差（暴烈画面配反差性安静声音）
- 情绪增强音为单点强调音（心跳/耳鸣/钟摆），不得演变为旋律性BGM

### 3. 后期备注栏（可选）
- 声桥（J-cut/L-cut）/ 匹配剪辑 / 时间转场 / BGM情绪方向 / 字幕与文字道具贴字提醒

### 4. 音色
- 全局资产表定义一次，段内不重复

## 十六、执行口诀（丹姐6月 v2.4版）

**总纲**：三层分明，冲突看仲裁表；流程六步——读本→资产表→规划表（含对账）→逐段产出→自检+复盘→交付含快照与回填

**开工**：定画幅、建资产表（定妆锚点+光源清单+开关+高危缓释策略）、出规划表（负载判定+集时长预算+台词对账基线）

**保真**：台词三零——零删减、零换序、零改归属；批次对账差额=0；回忆与长动作禁梗概化；语气词计字不计句

**拆段**：四断点优先（时空/微目标/阵营/情绪沉降），200字辅助；每15秒20-45字，短段按比例折算注明；拖长音×1.3-1.5上浮；超长单句走仲裁

**负载**：极高0.5-2秒急切掩穿模、中2-4秒、低可至6秒；时长=MAX(台词,动作,运镜,特效)或串行累加；真空期必补待机微动作；**每段强制附时长核算表显示计算过程（只给时间码=不合格）**；说话与占口动作必须串行；镜头内时间物理真实、压缩只能靠切镜省略；段总时长含定位帧≤15秒

**轴线**：每场建轴锁一侧；每镜标画左画右与面朝；越轴走过渡；多人主轴+区域固定；30°防跳剪

**方向**：出画左入画右；行进方向锁定；视线匹配；POV先建立看者；游离视线声明落点；高低差标仰俯；权力反转时仰俯同步反转

**空间**：站位九要素；严禁为台词清晰篡改真实距离与高低差；垂直交互写受力点禁"同层"；特写补空间确认句

**粒度**：细节匹配景别——远景宏观势态禁微表情、中景眉眼轮廓、特写全量；远景台词不写口型；焦外角色一句宏观锚点

**表情**：过程化+触发点绑定，禁抽象标签

**状态**：人物外观+环境道具双线连续；道具交接单镜完成；造型同场锁定

**衔接**：姿态变化有过渡；前后段动势/情绪丝滑承接

**切镜**：直接切；运镜只在镜头内；肢体接触=接触前切出→受击结果+遮挡借位；一镜到底段（声明）豁免、慎用

**镜头动势**：每镜必有动势；定镜+画内动势合法（≤30%、对话段≤50%）；旋转摇每段≤1次；缓慢运镜≥3秒

**节奏**：长短阵型外化情绪（场记区标注）；蓄水破堤；降维压迫；大场面≥30%涟漪镜头

**景别**：说话禁胸上特写；齐声仅限喊叫短句≤8字、长句改紧咬先后；条件特写三条件；情绪贴脸用听者特写+画外

**台词上镜**：场记区每句标出镜/画外/OS；画外+OS按字数≤50%；爆点出镜；OS默认关、启用须双轨绑定；复制区用自然语言表达（"画外传来XX的声音"）

**首帧**：钩子帧>新场景全景>换人（多人末镜取任一，优先剧情主动方）>单人替代帧；换人撞台词时用"画外台词压他人反应帧"标准解法

**全景/定位帧**：禁一切人声；新场景全景开场；多人全景缓释；≤2秒有动势；定位帧计入段时长；集尾豁免

**结尾**：叙事结尾禁全景；集尾悬念帧；集末出快照

**打光**：光源动机→情绪反差→性别缺省；光位同场锁定；阴影面部补漫反射；色温按题材统一

**闪回**：单独成段+统一编码+三明治闭环+分型时长+禁跨批次截断

**高危回避**：镜子=镜位视角（标准解法）；文字道具虚焦+画外读出；密集手部简化；肢体接触反穿模；多人正脸缓释

**音效**：与运镜联动；爆点三件套（静音真空/重音卡点/听觉反差）

**交付**：复制区/场记区物理分离——核算表、阵型、[光效]标记、括号标注、栏位名一律不入复制区；复制区全自然语言；[光效]写作自检用、交付删除、光效由基调承载；1900字只计复制区

**回填**：实算时长回填规划表；拆段重编必须重发规划表标注变更

**自检**：先🔴阻断15条（违一不出稿），再🟡质量31条；每批交付后复盘规则摩擦点
