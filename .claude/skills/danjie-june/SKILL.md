# 丹姐6月 v2.1 - AI短剧分镜执行技能

> 小说/剧本 → 短视频分镜执行稿
> 核心能力：拆段、轴线、运镜、光效、特效、音效全链路输出
> v2.1 修订要点：恢复场次规则与运镜术语表（v2.0回归修复）、出入画方向匹配、视线匹配与POV、画外台词机制、多人轴线与群演缓释、环境道具状态连续、光位锁定、造型/时段变体、节拍拆段规划表、集末状态快照、时间轴核算、AI高危画面回避清单

## 〇、三层规则体系与优先级仲裁 ⚠️ 全文总纲（先读本章）

### 1. 三层规则体系
本技能所有规则分属三层，遇到表述冲突先判断所属层：

- **剧作层**：台词、剧情、拆段——管"演什么"
- **视听语法层**：轴线、景别、运镜、打光设计、节奏——管"怎么拍"
- **提示词工程层**：禁用词、字数预算、参考图、防伪影——管"怎么写给模型"

⚠️ **关键认知**：提示词工程层的禁用词约束的是**写法**，不约束视听设计本身。
例：打光设计可以采用伦勃朗式侧光塑形（视听层成立），但提示词中不得出现"光斑"一词（工程层禁用），应换词表述为"面部一侧受光、另一侧渐变阴影"。**设计保留，换词表述。**

### 2. 全局优先级（高→低，规则冲突时高位胜出）
1. 台词完整性：零删减、不断裂
2. 全景/定位帧禁台词
3. 空间连续性：轴线、站位锁定、屏幕方向、出入画方向
4. 衔接连续性：动势、情绪、人物外观状态、环境道具状态
5. 提示词禁用词与字数预算
6. 画幅与安全区
7. 节奏约束：段时长、单镜时长、台词字数区间、时间轴核算
8. 镜头设计偏好：运镜多样性、景别丰富度、首帧换人
9. 光效风格偏好

### 3. 专项仲裁条款 ⚠️（逐条消除规则对撞）

| 冲突场景 | 仲裁结果 |
|---|---|
| 集首段：钩子帧 vs 新场景全景开场 | **钩子帧先行**（1-2镜），全景紧随其后交代空间（冷开场语法） |
| 换场景段：全景开场 vs 首帧换人 | **全景开场胜出**；首帧换人规则仅约束同场景延续段 |
| 段末定位全景 vs 结尾镜头禁全景 | 定位帧是叙事结尾镜头**之后的附加帧**，不算结尾镜头、不参与下段承接判断；**集尾段豁免定位帧**（悬念帧必须是最后画面） |
| 单句台词>45字且不可断、不可删 | 该段标注"超长台词段"，时长允许上浮至18秒（管线支持时）；管线不支持则在自然语气停顿处跨段接续并标注"台词跨段接续"，由后期负责音频无缝拼接 |
| 动作豁免段/闪回段/定位帧 vs 台词密度底线 | 豁免，不受"每段≥2句台词"与20字下限约束 |
| 打光设计用词 vs 禁用词表 | 设计保留，**换词表述**（禁用词表优先于一切光效表述） |
| 单人独白戏：首帧换人无人可换 | 首帧用道具/手部/背影/环境局部镜头替代 |
| 旁白禁令 vs 画外台词 | **画外台词合法**：场景内角色的现场说话声（说话者暂不在画内）；**旁白禁止**：叙述者/角色事后的解说声。判定标准：声音是否属于当前时空正在发生的对话 |
| 连续相同运镜禁令 vs 正反打定镜对切 | 正反打对切中双侧均为"定镜+画内动势"属合法常规（不同机位即不同镜头），不受连镜禁令限制；**运动运镜**仍不得连续同型同向 |

### 4. 模型版本复审注记
工艺层规则基于当前主流图生视频模型能力设定，应随模型迭代定期复审：
- 对口型能力提升 → 可放宽说话时景别限制与画外台词占比
- 多人同框稳定性提升 → 可放宽全景与群演崩脸缓释要求
- 多镜头时序支持增强 → 可调整生成管线选择

## 一、开工前置与执行流程

### 1. 执行流程总览 ⚠️ 六步SOP
```
①读本通读 → ②建全局资产表 → ③出节拍与拆段规划表（用户确认）
→ ④逐段产出执行稿 → ⑤每段过分级自检（🔴阻断→🟡质量）→ ⑥交付（资产表+规划表+全部段落+集末状态快照）
```
- ③规划先行的目的：先定全局节奏与时长预算，避免写到一半发现节奏失衡推倒重来
- 局部返工：单镜头生成失败时，按镜头粒度重出，不牵连整段

### 2. 画幅声明 ⚠️ 开工必须先定
- **默认 9:16 竖屏**（用户声明横屏则按 16:9 执行，并恢复横屏语法）
- **竖屏构图规范**：
  - 单人构图优先，人物占画面主导
  - 纵向三层调度：前景元素压底边 / 人物中层 / 环境顶层——**用纵深替代横向调度**
  - 头顶留白适度，避免大面积空顶
  - **对话戏用单人正反打，不用过肩**（竖屏过肩肩膀占比过大）；可用前景虚化肩影暗示对方存在
  - **安全区**：画面右侧边缘约15%为互动按钮区、底部约20%为字幕/进度条区——人脸、手部关键动作、关键道具必须避开这两区
- 16:9 横屏时：恢复过肩镜头、三分法、横向调度等横屏语法

### 3. 全局资产表 ⚠️ 每个项目开工输出一次
开工先建表，后续每段只引用ID，不重复描述：

```
【角色表】角色ID | 姓名 | 性别 | 音色描述 | 打光缺省方案
  └ 造型变体：造型ID(A/B/C…) | 参考图(有/无) | 适用场次范围
【场景表】场景ID | 名称 | 内/外景 | 主光源清单(窗光/灯光/烛光/月光/霓虹等) | 主光方向(画左/画右/顶/背) | 色温基调
  └ 时段变体：时段ID(日/夜/黄昏…) | 参考图(有/无) | 光线状态
【道具表】道具ID | 名称 | 归属角色 | 参考图(有/无)
```

- **造型变体**：角色换装必须有剧本支撑（换场/换日/明确换装动作），每段引用"角色ID-造型ID"，同场次内造型锁定不得漂移
- **时段变体**：同场景昼夜不同按时段ID区分，时间跳跃按换场处理（见场次规则）
- **场景表的主光源清单与主光方向是打光设计的依据**（见第十一章"光源动机"与"光位锁定"）
- 音色在角色表定义一次，段内不再重复输出
- 无参考图的资产 → 提示词中禁止描述其外观（见第十二章禁用词表）

### 4. 节拍与拆段规划表 ⚠️ v2.1新增（逐段产出前必须先出）
```
【节拍规划表】集数 | 段号 | 一句话内容 | 段类型 | 时长预算 | 场景ID-时段 | 出场角色-造型 | 钩子/反转/卡点标记
```
- **集时长预算**：默认单集成片60-120秒≈5-8段（按用户平台要求调整），先分预算再写稿
- 全剧反转点、情绪顶点、付费卡点在规划表上标记完毕后，再进入逐段执行
- 规划表输出后建议用户确认节奏再批量产出

### 5. 参考图优先级
**参考图 > 用户场景要求 > 无（无则不给外观/场景词）**
- 有参考图：按图实际画面描述服装/长相/场景，不得编造图中未呈现的内容
- 有场景要求无图：严格按场景要求生成，不添加用户未提及的元素
- 都没有：只写动作、情绪、运镜、光效、空间关系，**绝不自行编造任何外观/场景词**
- ⚠️ **剧本中的服装/长相描述一律不参考**——即使剧本写了"她穿着白色衣服"，提示词也不得引用（除非有参考图且与剧本一致）

### 6. 生成管线声明
- **默认管线**：图生视频，一段=一条提示词（含多镜头时序），首帧图=段首镜头静帧
- **分条管线**（用户声明或模型不支持多镜头时序时）：每镜头单独成条提示词，首尾帧接力；段级规则（站位/轴线/情绪衔接）仍跨条生效
- **段间接力**：同场景延续段，上段末帧（或定位帧）应作为下段首帧图的空间参考底图

## 二、剧作层：场次、拆段与台词

### 1. 场次规则 ⚠️（v2.1恢复）
- 一切按剧本场次和场景来，**一段只属于一个场次**
- 场次/场景切换必须同步拆段，**不允许自行更改剧本场景设定**
- **同场景内时间跳跃**（如深夜→清晨、数小时后）按换场处理：拆段 + 引用场景时段变体 + 光线状态同步更新 + 后期备注标注时间转场
- **平行剪辑**（两线交叉）：按线分段交替输出，每条线独立遵守轴线、站位、状态连续规则

### 2. 拆段基础规则
- 按剧情完整拆段，**不漏台词、绝不删减台词**
- 以约200字一段为基础参考
- 优先保证：台词不断裂、词气不断裂、动作承接不断裂、情绪落点不断裂
- **不允许为了凑字数硬拆完整表达**

### 3. 台词整合规则
- 单句台词超30字 → 按两句整合为一段
- 单句台词低于30字 → 按三句整合为一段
- 前提始终是：不能断裂台词、不能破坏完整表达、不能拆散与台词紧相连的动作和情绪

### 4. 台词字数规则 ⚠️ 核心规则（以15秒为单位）
- **每15秒台词不超过45字、不低于20字**（不含标点）
- 换算依据：中文常速约4-5字/秒，45字≈9-11秒台词，在15秒段内留足反应镜头与气口；20字下限防止凑时长拖节奏
- **⚠️ 绝不删减原剧本台词**——台词超标必须通过拆段控制，**为控制字数删减任何台词内容是严格禁止的**
- 单句>45字且无法拆分时 → 按专项仲裁条款处理（超长台词段）
- 拆段后在剧本内容栏附注字数统计（如：台词字数统计：42字，段时长14秒，符合15秒内20字≤台词≤45字）
- 豁免：动作豁免段、闪回段、定位帧不受20字下限约束

### 5. 闪回规则 ⚠️（v2.1强化）
- 遇到"闪回"字样 → **必须单独成段**，段类型标注【闪回段】
- **闪回视觉编码**：全剧统一一种闪回标记（色温偏移 或 降饱和，二选一，写入场景表备注），所有闪回段执行同一编码，不得一段一个样
- **进出闪回直接切**（可配音效提示如回声音桥），白闪特效慎用；闪回内部照常遵守轴线与连续性规则
- 闪回段豁免台词密度底线；无台词闪回按纯动作段时长控制（≤4秒，镜头≤2个）

### 6. 台词密度底线 ⚠️
- **每段至少2句台词**（硬性底线，豁免段除外）
- 仅1句台词的段落 → 总时长≤6秒，镜头≤3个（尽量合并到相邻段）
- 纯动作/无台词段落 → 总时长≤4秒，镜头≤2个（**动作豁免段除外**）
- 台词不足2句时的补足方式：①合并相邻短段 ②拆段时主动将有台词的相邻内容归入同一段

### 7. 动作戏豁免条款 ⚠️
- 打戏/追逐/坠落/仪式等**无台词动作段**：允许 6-15 秒、2-6 个镜头，不受台词密度约束
- **必须写出动作编排**：招式过程/攻防节奏/受击反应/环境互动，不允许"两人打斗"一笔带过
- 跟拍、急推急拉、环绕等辅助运镜在动作豁免段解禁为主力
- 动作豁免段前后必须有台词段衔接，不允许连续多个无台词段

## 三、空间系统：轴线、方向、站位、视线 ⚠️ 核心章节

### 1. 轴线规则（180°规则）⚠️ 空间第一规则
- **每场戏开场即建轴**：以核心两人连线（对话戏）或运动方向（动作戏）为轴线，**全场机位锁定在轴线一侧**
- **每个镜头必须标注屏幕方向**：人物位于画左/画中/画右 + 面朝画左/画右
- **对话正反打方向锁定**：A居画左面朝画右 ↔ B居画右面朝画左，全场保持不变
- **越轴管理**：确需越轴时，必须通过以下三者之一过渡，禁止硬越轴：
  1. 沿轴中性镜头（人物正面/正背面机位）
  2. 人物走位带轴（镜头跟随人物移动自然过轴，越轴后新轴线立即锁定并标注）
  3. 无方向性插入镜头（道具/手部特写）
- **30°规则**：同一主体直接相切的两个镜头，机位角度变化须≥30°或景别变化≥一级，否则视为跳剪
- **AI落地写法**：提示词中明确写"XX位于画面左侧、面朝画面右侧"——这是防止AI生成方向翻转的唯一手段，每镜必写

### 2. 多人戏轴线与群演 ⚠️ v2.1新增
- **三人以上场面**：以核心冲突双方连线定**主轴**，第三方角色固定区域（画左/画中/画右）后按副轴处理；单人反应插入镜头维持该角色在主轴侧的既有朝向，不破主轴
- **群演/背景人物崩脸缓释**：背景群演**不给正脸**——虚化、背影、肩部以下取景、远景化处理任选；群演人数在段落标注；群演不参与轴线计算，但行动方向感必须与场面调度一致
- 群演表情要求降级执行：远景群演只需姿态符合氛围，不强求微表情

### 3. 运动方向与出入画 ⚠️ v2.1新增
- **出入画方向匹配**：同一移动过程跨镜头时，出画方向与入画方向互补——**出画左 → 下一镜从画右入画**；违反即空间跳变
- **行进方向锁定**：走路/追逐/赶路全程屏幕方向锁定（如向画右=去程、向画左=返程），中途换向必须有转弯镜头或正面/背面中性镜头过渡
- 入画=登场、出画=离场留空，出入画本身是镜头语言，可配合悬念使用
- 段落如有出入画，必须在轴线栏记录方向，供下段承接

### 4. 视线匹配与POV ⚠️ v2.1新增
- **视线匹配剪辑**：人物看向画外某物 → 下一镜可接所看对象（POV主观镜头或客观插入镜头），**对象的空间方位必须与视线方向一致**（向画右看→对象在空间逻辑的画右）
- **POV规范**：POV镜头前必须先有"看的人"的镜头建立视线；POV画面内不出现看者本人；POV结束后通常回接看者反应
- POV是特写禁令的合法补充通道：看信、看手机、看伤口、看远处来人，均可用POV呈现
- **机位高度=视线高度**：对话戏机位默认取人物眼高；俯仰偏离眼高必须是权力关系表达（高位俯拍=压制、低位仰拍=威压），不得无动机歪机位

### 5. 位置锁定规则
- **所有人位置锁定**：每段的人物站位必须与上段末尾完全一致
- 不允许擅自移动未发生走位动作的角色；位置变化必须由剧本明确动作支撑
- 走位变化必须精确写出新位置（相对空间坐标），下一段首帧和空间关系栏必须精确定位到走位后的最新位置
- **后退半步也算位置变动**
- 人物从蹲/坐/跪等低位起身后，必须精确写出站起后的位置，该位置一旦确定，后续所有段落严格连续承接

### 6. 每段站位描述六要素
必须写清楚：左侧 / 中间 / 右侧 / 前景 / 后景 / 中轴关系
**不允许写"同上站位"、"站位不变"等**

### 7. 视线关系位
每段都必须写：
- 角色A看向谁、角色B看向谁
- 是否形成对视、视线是否对上
- ⚠️ 视线朝向必须与轴线栏的屏幕方向一致（A面朝画右看B，则B必在A的画右方向）

### 8. 动势衔接规则 ⚠️
- **所有人物的姿态变化必须有过渡过程**，不允许姿态突然跳变
- 坐→站必须写"撑桌起身""缓缓站直"等过渡动作；跪→站、站→蹲、蹲→趴等同理
- 姿态变化前必须有动势铺垫（身体前倾、重心转移、手部支撑等）
- **⚠️ 前后段动势丝滑衔接**：下一段首帧人物的姿态、动作方向、身体朝向必须严格承接上一段末帧状态
- **⚠️ 动势衔接自检**：写完每段必须回顾上一段末帧人物状态，确认当前段首帧完全匹配，无割裂感

## 四、人物与环境状态、表演

每段都必须补：
1. **实际出场人物**（含造型ID引用）
2. **人物特殊道具**（明确哪只手拿道具）
3. **人物姿态状态**：站、跪、跌坐、俯身、缓步前行、抬手、转身、前倾、后仰、低头、抬眼等
4. **人物情绪状态**：情绪必须明确，动作必须服务情绪

### 站桩禁止 ⚠️ 核心规则
- **绝对不允许站桩式念台词**，禁止人物反应呆板
- **人物一旦入镜必有反应**——无论是否当前说话者，入镜即须有符合场景情绪的表情反应或肢体微动作
- 角色说台词时，必须伴随**手部动作和表情变化**；部分剧情可增加走位
- 台词必须挂在动作和情绪上完成表达
- **避免死脸**：背景人物/旁观者也必须呈现与场景氛围一致的表情状态（群演按降级规则执行）

### 人物外观状态连续性 ⚠️
- **人物外观状态必须全程连续**：被水泼湿、出汗、受伤流血、泪痕、泥土沾面、衣衫破损等状态变化，从发生起，**后续所有段落所有镜头必须保持该状态描述**
- 状态持续到剧本明确发生消除该状态的动作
- **每段人物道具姿态栏必须复述当前持续中的外观状态**，不允许凭空消失或时有时无

### 环境与道具状态连续性 ⚠️ v2.1新增
- **环境状态同样全程连续**：雨雪在下、烛火燃烧、打翻的桌椅、碎裂的花瓶、洒落的饭菜、溅出的水渍——从发生起持续保持，直到剧本明确消除（收拾/换场）
- 每段场景栏复述持续中的环境状态
- **道具交接规则**：关键道具的拿起/放下/递接动作**尽量在单镜头内完成**；必须跨镜时，两侧镜头严格标注道具位置与持有手，状态无缝
- 杯中水位、信纸折痕等微状态在关键剧情道具上同样追踪

### 情绪衔接规则 ⚠️
- **同场次人物情绪全程连贯递进，不得有任何割裂感**：不允许前一段愤怒、下一段若无其事
- 情绪转折必须由剧本台词/动作支撑，不可自行跳变
- 旁观角色情绪反应必须与当前场景情绪一致
- **⚠️ 前后段情绪丝滑衔接**：下一段首帧情绪必须严格承接上一段末帧情绪落点
- **⚠️ 情绪过渡必须有载体**：通过台词、动作、表情、呼吸等具体载体呈现过渡，不可凭空跳变

## 五、节奏与景别

### 时间约束
- **常规单镜2-4秒**（最长不超过4秒）；**反应镜头/插入镜头允许1-2秒**；**全景/定位帧≤2秒**
- 每段总时长：根据台词量灵活调整，**最长不超过15秒**（超长台词段例外，≤18秒）
- **台词少的段落要短！不要凑时长！**
- 段时长参考梯度：
  - 仅1句台词 → 4-6秒，2-3个镜头（尽量合并到相邻段）
  - 台词少（2句）→ 6-8秒，3-4个镜头
  - 台词中等（3-4句）→ 10-12秒，4-5个镜头
  - 台词多/情绪爆发 → 12-15秒，5个镜头
  - 动作豁免段 → 6-15秒，2-6个镜头
- **⚠️ 时间轴核算（v2.1新增）**：分秒区间必须首尾相接、无重叠、无空洞，区间总和=段时长标注，台词秒数与字数换算（4-5字/秒）相符
- 禁止长镜头：连续相同运动运镜=视觉长镜头，必须避免

### 景别规范 ⚠️
- 常规景别：全景 / 中景 / 中近景 / 近景
- **⚠️ 说话期间禁止胸部以上特写（对口型规避）——硬规则，无例外**（情绪贴脸需求可改用"听者特写+画外台词"方案，见第九章）
- **⚠️ 条件许可面部特写**：同时满足以下三条 → 允许胸部以上面部特写，每段≤1个，1-2秒：
  1. 非说话时刻（无对口型需求）
  2. 该角色有定妆参考图（一致性有保障）
  3. 情绪爆点/关键反应瞬间
- **无参考图角色：维持禁特写**
- 眼睛/嘴巴大特写：**高风险选项**（画幅越紧越易崩），仅在有强参考图且确属情绪顶点时使用

### 焦段表

| 景别 | 推荐焦段 | 说明 |
|------|----------|------|
| 全景/定位帧 | 24-35mm | 空间交代 |
| 中景 | 35-50mm | 调度主力 |
| 中近景 | 50-85mm | 对话主力 |
| 近景 | 85mm | 压缩背景、浅景深 |
| 面部特写（条件许可） | 85-105mm | 必须背景虚化 |

- 广角贴近人物产生畸变，仅用于压迫/眩晕/失衡的刻意表现

### 景别丰富度
- **必须使用多种景别**，避免连续相同景别
- 景别变化要有逻辑（情绪递进、空间转换等），并遵守30°规则防跳剪

## 六、镜头与运镜 ⚠️ 核心章节

### 1. 切镜规则 ⚠️
- **切镜头直接切，绝对不能用运镜方式切换镜头**
- **运镜仅作用于单个镜头内部，绝不允许用于镜头间过渡**
- 禁止：❌甩镜切 ❌推进切 ❌拉远切 ❌平移切 ❌任何以运镜运动替代切镜的衔接
- **切点选择（v2.1新增）**：跨条生成的相邻镜头**慎用"动作中切"**（两条生成的动作难以精确衔接），优先在**动作完成点**或**反应点**切；同一条生成内的多镜头可用动作中切
- 场次间转场默认直接切；匹配剪辑（动作匹配/图形匹配）建议写入后期备注

### 2. 动势原则 ⚠️
- **每个镜头必须有"动势"——镜头运动或画内主体运动，至少其一**
- **定镜许可**：定镜（固定机位）+ 明显画内动势 = 合法镜头
  - 适用：对峙僵持、权威感、构图压迫、惊愕定格、收束留白、正反打对切
  - 画内动势：人物动作、表情变化、呼吸起伏、环境元素运动（风、光影移动、雨落）
  - **定镜全篇占比指导≤30%；对话正反打段允许上浮至50%**；动作段应趋零
- **绝对禁止：定镜 + 人物静止无表演 = 冻结帧**

### 3. 运镜分级
- **主选（优先使用）**：左右平移 / 缓慢推进 / 拉远 / 定镜+画内动势
- **辅助（剧情需要时使用）**：旋转摇上、旋转摇下（**每段≤1次、速度≤匀速，留给情绪转折点**）、升镜、降镜、半环绕、跟拍（动作/追逐专用）、急推/急拉（爆点专用）、纵深推进、低角度贴地、俯拍/上帝视角
- **慎用**：全环绕（AI极易崩）
- **禁止**：甩镜
- **多样性规则**：
  - **连续两镜不得使用相同的运动运镜（同型同向）——硬规则**；正反打定镜对切豁免（见仲裁表）
  - 单一运镜方式占比参考上限40%（指导值，不做机械配额）
  - **运镜选择以"表达什么"为准，禁止为凑占比机械轮换**

### 4. 运镜术语表 ⚠️（v2.1恢复，统一用词）
| 术语 | 定义 |
|------|------|
| 推进 | 镜头向前推近，聚焦人物上半身/手部/关键道具 |
| 拉远 | 镜头向后拉开，露出更完整空间 |
| 升镜/降镜 | 镜头垂直缓慢上升/下降 |
| 旋转摇上 | 从低位边缓慢旋转边向上摇起（情绪升华/觉醒/登场） |
| 旋转摇下 | 从高位边缓慢旋转边向下摇落（情绪沉落/压迫递增） |
| 左/右平移 | 画面匀速水平横移 |
| 斜向滑动 | 沿斜上/斜下角顺滑滑动 |
| 半环绕 | 围绕人物缓慢环绕约30° |
| 全环绕 | 围绕人物360°（AI极易崩，慎用） |
| 跟随跟拍 | 贴身跟随人物移动 |
| 侧面跟拍 | 侧面平行跟随 |
| 纵深推进 | 沿通道/纵深线向前推进 |
| 低角度贴地 | 贴地面低角度拍摄 |
| 俯拍 | 高位向下俯拍/上帝视角 |
| 组合运镜 | 推进转摇上、拉远转升镜、平移转推进等 |
| 氛围运镜 | 前景遮挡推进、逆光勾边推进、雾中推进 |
| 穿梭运镜 | 穿窗镜头、回廊穿梭 |

### 5. 运镜配合情绪与台词 ⚠️
- 情绪递进时运镜加速或推进；情绪沉落时放缓或拉远
- 台词节奏快慢与运镜速度匹配；关键台词/情绪转折点运镜要有对应变化（急推、旋转摇上、或转为定镜凝滞）
- **镜头语言对照**：推进=压迫聚焦 / 拉远=疏离释然 / 升镜=升华力量 / 降镜=沉重无力 / 平移=观察流动 / 急推急拉=震惊爆发 / 定镜=对峙凝滞威压 / 入画=登场 / 出画=离场留空
- 每个运镜选择必须能回答"这个运镜在表达什么"

### 6. 运镜场景对照表

| 剧情场景 | 推荐运镜方式 | 推荐速度 |
|----------|--------------|----------|
| 交代环境/空间关系 | 全景缓推、俯拍、升镜拉远 | 缓慢 |
| 氛围铺垫/情绪酝酿 | 缓慢推进、左右平移、定镜+画内动势 | 缓慢 |
| 紧张对峙/冲突升级 | 定镜凝滞、推进、平移 | 匀速至快速 |
| 动作场面/情绪爆发 | 跟拍、急推、环绕（豁免段解禁） | 快速 |
| 对话交流/信息传递 | 单人正反打+微平移或定镜、缓慢推进、反应镜头 | 匀速 |
| 高潮/逆转/关键瞬间 | 急推、急拉、旋转摇上（每段≤1次） | 快速 |
| 结尾收束/悬念留白 | 缓慢拉远、定镜+画内动势、旋转摇下 | 缓慢 |
| 单人独白/内心戏 | 缓慢推进、微平移、定镜 | 缓慢 |
| 人物出场/登场 | 推进、纵深推进、低角度、入画 | 匀速 |
| 情感转折/心绪变化 | 推进转拉远、升降、由动转定 | 由缓转匀 |

### 7. 运镜速度标注规范
每条运镜必须标注速度，格式：`运镜方式（速度）`
- 缓慢：氛围铺垫、情绪酝酿、回忆思念、结尾留白
- 匀速：对话推进、信息传递、人物出场、日常场景
- 快速：情绪爆点、冲突对峙、动作场面、卡点反转
- ⚠️ 旋转类运镜速度≤匀速
- **⚠️ 速度与镜头时长匹配（v2.1新增）**：缓慢运镜需≥3秒镜头才可感知；1-2秒短镜头只配微动（微推/微移）或定镜+画内动势

### 8. 气口与声桥 ⚠️
- **留1秒气口**：最后一句台词结束后，留至少1秒画面延续（表情反应、动作延续、环境呼吸），不让台词卡着时间线尾巴结束（卡尾帧会吃字）
- **声桥提示（可选）**：气口处可在"后期备注"栏标注 J-cut（下段首句台词预压入本段气口）或 L-cut（本段环境音延入下段开头）；仅作为后期剪辑备注，**不写入提示词正文**

### 9. 每条运镜必须包含
景别（焦段）/ 运镜方式（速度）/ 构图方式 / 镜头语言（表达什么）/ 人物表情情绪 / 人物动作 / **屏幕方向与视线** / **台词呈现方式（出镜说话/画外台词/无台词）** / 空间关系 / **[光效]标记**

### 10. 构图类型（按画幅适配）
- 竖屏主力：纵深引导线、前景压边（压底边）、高低位压迫、中心压迫、人物偏置、上下分层
- 横屏补充：对角线、三分法、左右对峙、过肩构图
- ⚠️ 构图必须与已声明画幅匹配；**镜面/水面反射构图慎用**（AI反射极易崩），确需时反射内容虚化或只取局部

## 七、全景与站位定位帧

### 1. 全景禁台词 ⚠️ 绝对规则（优先级第2位）
- **全景/定位帧中不允许任何角色说话、OS、VO、画外台词或画外音**——进入全景镜头，所有声音通道静默（环境音除外）
- 如果台词未说完，先完成台词再出全景

### 2. 新场景全景开场
- **新场景首次出现时必须以全景开场**，先交代完整空间环境，再切入人物（集首段钩子帧例外：钩子先行、全景随后）
- **⚠️ 多人全景崩脸缓释**：多人全景是AI崩脸最高发镜头——优先用**背影机位/高机位俯拍/剪影/拉开距离降低面部像素占比**，避免多人正脸全景

### 3. 站位定位帧 ⚠️
- **定义**：叙事结尾镜头**之后的附加帧**，≤2秒，无台词，轻微运镜或画内动势，功能是向后续段落的生成提供站位参考
- **触发条件**：①第一段结尾（看清初始站位）②任何人物位置/姿态/面朝方向变化的段末 ③无变化不出（避免冗余）
- **豁免**：集尾段不出定位帧（悬念帧必须是最后画面）
- **性质判定**：定位帧不算结尾镜头、不参与首帧换人判断
- 定位帧同样适用多人崩脸缓释（背影/高机位/剪影）

### 4. 推进剧情的全景
- 全景用于展示走动/位移等动态过程（追逐、入场、离场）时允许推进剧情，**但必须搭配运镜**（跟拍推进/平移跟拍/升镜俯拍），纯静止全景不得推进剧情

## 八、首帧与结尾镜头

### 1. 首帧优先级（从高到低，取第一个命中项）
1. **集首段** → 钩子帧（全剧最强冲突/悬念/高情绪画面；跨集时承接上集末状态快照）
2. **新场景段** → 全景开场（含多人崩脸缓释）
3. **同场景延续段** → 换人：首帧为上一段叙事结尾镜头人物**以外**的角色
4. **单人戏** → 道具/手部/背影/环境局部镜头替代
- 对话戏延续段：竖屏从单人正反打开始（横屏可从过肩开始）
- 首帧即图生视频的种子帧，必须描述精确（人物、姿态、屏幕方向、景别、光效）

### 2. 结尾镜头规则
- **叙事结尾镜头禁全景**；可以是：中景、中近景、近景、道具镜头、人物反应镜头、环境局部镜头
- 结尾镜头必须服务下一段承接；**下一段首帧不得从该人物开始**（同场景延续时）
- 段末如触发定位帧，定位帧附加在叙事结尾镜头之后
- **集尾段：结尾镜头=悬念帧**（见第十章）

## 九、反应镜头与台词上镜策略 ⚠️ v2.1扩充

### 1. 反应镜头规则
- 人物说话时，**必须给其他重要角色的表情反应镜头**，避免站桩说话
- **重点情绪台词处**，必须给到其他人的表情反应镜头
- **⚠️ 人物一旦入镜必有反应**——画面中出现的人物必须有与场景情绪一致的微表情/微动作
- 反应镜头以近景/中近景为主，时长1-2秒，必须搭配运镜或画内动势（微平移/微推进/定镜+表情变化）
- **所有人说话不要正对镜头说话**；可以正面、侧面、转身背面拍摄

### 2. 台词上镜策略 ⚠️ v2.1新增（对口型风险管理核心）
每句台词必须标注呈现方式，三选一：
- **出镜说话**：说话者在画内开口（需对口型）——景别最小近景，重要情绪台词、宣言、对峙台词优先出镜
- **画外台词**：说话者暂不在画内，台词压在**听者反应镜头**或空间镜头上播出——完全规避对口型风险；信息过渡型台词、连续长对话的次要句优先画外
- **无台词**：纯反应/动作/定位镜头
规则：
- **画外台词 ≠ 旁白**：画外台词是当前时空正在发生的现场说话声；旁白是叙述解说声（禁止）
- **每段画外台词占比≤50%**——全画外=广播剧，失去表演；爆点台词必须出镜说
- **"听者特写+画外台词"** 是情绪贴脸时刻的合法组合：说话者声音压在听者面部特写上（听者满足条件特写许可时）
- 全景/定位帧禁一切台词（含画外）——绝对规则不变

## 十、集级结构与跨集管理

分镜层的钩子责任 = **选帧**：同样的剧本内容，开场选最强画面、结尾选最吊画面。

- **集时长预算**：默认单集成片60-120秒≈5-8段（按用户平台要求调整），在节拍规划表中先行分配
- **集首段**：第一镜=钩子帧——把全集最强冲突/悬念/高情绪画面调度到开场前3秒；允许冷开场（钩子先行、全景随后交代空间）
- **集尾段**：结尾镜头=悬念帧——反转揭示/危机定格/情绪顶点；禁全景、豁免定位帧
- **付费卡点**：用户标注卡点段时，该段按集尾段标准执行，收在最强悬念帧
- **集末状态快照（v2.1新增）**：每集末段之后输出快照——各角色位置/姿态/情绪/外观状态/造型ID + 场景环境状态，供下集开工承接；下集集首钩子帧从快照状态出发
- 用户未提供分集信息时按单集处理：首段执行集首规则、末段执行集尾规则

## 十一、光效与打光

### 1. 打光决策顺序 ⚠️（依次判断，高位优先）

**第一步：光源动机（motivated lighting）**
- 查场景表主光源清单，**主光方向/性质必须能被场景内光源解释**（窗光/灯光/烛光/月光/霓虹/天光）
- 提示词写明光从哪来（如"暖黄灯光从画右侧上方照下"）

**第二步：情绪反差**
- 冲突/压迫=硬光高反差；温情/日常=柔光低反差；审判/压抑=顶光；恐惧/不安=低位光；悬疑/撕裂=侧光分割（半明半暗）

**第三步：缺省方案**（无明确光源依据与情绪指向时才使用）
- 男性=侧光塑形（伦勃朗式）——提示词表述为**"面部一侧受光、另一侧渐变阴影、立体硬朗"**，⚠️不得写"三角光斑"
- 女性=柔和顶前光（蝴蝶式）——提示词表述为**"正面柔光、面部立体柔美"**，⚠️不得写"蝴蝶阴影/光斑"
- ⚠️ 性别打光仅是缺省值：悲情/惊悚/崩溃戏按情绪反差打光，不得机械套用美颜光

**第四步：轮廓光**
- 近景/中近景/氛围镜头**默认侧逆光勾边**分离人物与背景——**前提是场景存在可解释的背光源**
- 光源逻辑不成立时（如正午顺光外景），**改用色彩分离/景深分离**，不强行逆光

### 2. 光位锁定 ⚠️ v2.1新增
- **主光方向同场次锁定**：场景表登记主光方向（如"窗在画左"），该场次所有段落所有镜头主光方向保持一致——光从画左来就一直从画左来，正反打两侧的受光面要符合同一光源逻辑
- 光位变化必须有剧情支撑（开灯/熄烛/日落），变化后新光位锁定并标注

### 3. 色温规则
- **同场次色温必须统一**；场次间氛围转变时，色温通过过渡段逐步转换，不可硬切
- **逆光色温必须与主光色温一致**

## 十三、声音与特效

### 1. 特效提示词
- 特效必须服务剧情，和人物动作、环境反馈、镜头变化同步，必须写成可视化内容

### 2. 音效建议（与运镜联动）
- 环境音 / 动作音 / 道具音 / 特效音 / 情绪增强音
- 音效节奏与运镜速度/方式匹配（急推配重音、缓推配渐强、定镜配环境底噪）
- 情绪增强音指音效性质的单点强调音（心跳声、耳鸣声、钟摆声），不得演变为旋律性BGM

### 3. 后期备注栏（可选）
- 声桥提示（J-cut/L-cut）/ 匹配剪辑建议 / 时间转场标注 / BGM情绪方向（仅方向词，供后期参考）/ 字幕后期添加提醒 / 文字道具后期贴字提醒

### 4. 音色
- 在全局资产表角色表中定义一次，段内不再重复

## 十四、AI视频输出质量自检清单 ⚠️ 分级执行

每完成一段分镜，先过🔴阻断项（任一不合格立即修正，不得输出），再过🟡质量项。

### 🔴 阻断项（出现即修正）

| # | 检查项 | 合格标准 |
|---|--------|----------|
| R1 | 台词是否完整 | 未删减任何台词、未为控字数精简 |
| R2 | 全景/定位帧是否静默 | 无任何角色说话/OS/VO/画外台词 |
| R3 | 空间方向是否连续 | 屏幕方向/视线方向前后一致；越轴有合法过渡；出入画方向互补；行进方向锁定 |

| R7 | 前后段动势是否衔接 | 首帧姿态/动作/朝向严格承接上段末帧 |
| R8 | 前后段情绪是否衔接 | 首帧情绪严格承接上段末帧落点，过渡有载体 |

| R12 | 是否用运镜切镜 | 无甩镜/推进切/拉远切/平移切，切镜直接切 |
| R13 | 时间轴是否核算 | 分秒区间首尾相接、无重叠无空洞、总和=段时长、台词秒数与字数相符 |
| R14 | 场次是否合规 | 一段一场次；换场/时间跳跃已拆段；未自行改场景 |

| # | 检查项 | 合格标准 |

## 十六、执行口诀（丹姐6月 v2.1版）

**总纲**：三层分明——剧作管演什么、视听管怎么拍、工程管怎么写；冲突看仲裁表，高位胜出

**流程**：读本→资产表→节拍规划表（用户确认）→逐段产出→分级自检→交付含集末快照

**开工**：先定画幅（默认9:16竖屏+安全区）、先建资产表（角色造型变体/场景时段变体/光源清单与光位）、先出规划表（集时长预算60-120秒≈5-8段）

**场次**：一段一场次，换场必拆段，不许自行改场景；时间跳跃按换场处理（时段变体+光线同步）

**拆段**：不漏不删台词；每15秒20-45字（常速4-5字/秒），超标拆段、不足合并；超长单句走仲裁；附字数统计

**轴线**：每场建轴、机位锁一侧；每镜标画左画右与面朝方向；越轴走合法过渡；多人戏主轴+区域固定；30°规则防跳剪

**方向**：出画左下镜入画右；行进方向全程锁定，换向必有过渡镜头；看向画外→下镜接所看之物且方向一致；POV先建立"看的人"

**位置**：站位锁定、与上段末尾一致；后退半步也算变动；六要素全写、禁"同上"

**状态**：人物外观（湿/血/泪/汗）与环境道具（雨雪/翻倒/碎裂）双线全程连续；道具交接单镜内完成；造型同场锁定不漂移

**衔接**：姿态变化必有过渡动作；前后段首末帧姿态/朝向/情绪丝滑承接，过渡必有载体

**切镜**：直接切；运镜只在镜头内部；禁甩镜；跨条生成慎用动作中切，优先动作完成点/反应点切

**镜头动势**：每镜必有动势——运镜或画内运动；定镜+画内动势合法（全篇≤30%、对话段≤50%），定镜+静止=冻结帧（禁止）；连续两镜运动运镜不同型同向（正反打定镜对切豁免）；旋转摇每段≤1次；缓慢运镜配≥3秒镜头

**景别**：每镜标焦段；说话期间禁胸上特写（硬规则）；非说话+有参考图+情绪爆点=允许面部特写；情绪贴脸可用"听者特写+画外台词"

**台词上镜**：每句标注出镜/画外/无台词；画外台词压反应镜头规避对口型（≠旁白）；画外占比≤50%；爆点台词必须出镜说

**全景**：禁一切台词（绝对规则）；新场景全景开场（集首让位钩子帧）；多人全景必做崩脸缓释；≤2秒、必有动势

**定位帧**：叙事结尾镜头之后的附加帧；首段结尾、位置/姿态/方向变化后触发；无变化不出；集尾豁免

**首帧**：集首钩子帧（承接上集快照）> 新场景全景 > 同场景换人 > 单人戏替代帧

**结尾**：叙事结尾禁全景、服务承接；集尾收悬念帧、付费卡点同理；集末出状态快照

**反应**：说话给他人反应；入镜必有反应；群演不给正脸（虚化/背影/远景）

**打光**：光源动机第一（查光源清单）、情绪反差第二、性别缺省第三；主光方向同场锁定；近景默认侧逆光勾边但须光源成立；同场色温统一、按题材冷暖表调配；丁达尔仅微粒场景

**高危回避**：文字道具虚焦+画外读出或后期贴字；镜面反射慎用；密集手部交互简化；多人正脸全景缓释

**禁用词**：眼神光/面部光斑永不写（设计保留、换词表述）；无参考图不写服装长相场景词；剧本外貌描述一律不参考；画面无文字；无BGM无旁白（干声交付，后期统一加）

**字数**：1900字只计提示词正文；元信息不计；[光效]交付时展开

**节奏**：时间轴首尾相接无重叠无空洞、总和=段时长；气口≥1秒；可标J/L声桥

**豁免**：动作戏6-15秒解禁跟拍急推（必写动作编排）；闪回单独成段+全剧统一视觉编码；豁免段不受台词密度约束

**自检**：先过🔴阻断项（14条，违一不出稿），再过🟡质量项（27条）
