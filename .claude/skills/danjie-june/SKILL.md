# 丹姐6月 v2.0 - AI短剧分镜执行技能

> 小说/剧本 → 短视频分镜执行稿
> 核心能力：拆段、轴线、运镜、光效、特效、音效全链路输出
> v2.0 修订要点：三层规则体系与优先级仲裁（消除规则死锁）、180°轴线系统、竖屏画幅规范、全局资产表、定镜许可、条件特写、光源动机打光、集级钩子结构、动作戏豁免

---

## 〇、三层规则体系与优先级仲裁 ⚠️ 全文总纲（先读本章）

### 1. 三层规则体系
本技能所有规则分属三层，遇到表述冲突先判断所属层：

- **剧作层**：台词、剧情、拆段——管"演什么"
- **视听语法层**：轴线、景别、运镜、打光设计、节奏——管"怎么拍"
- **提示词工程层**：禁用词、字数预算、参考图、防伪影——管"怎么写给模型"

⚠️ **关键认知**：提示词工程层的禁用词约束的是**写法**，不约束视听设计本身。
例：打光设计可以采用伦勃朗式侧光塑形（视听层成立），但提示词中不得出现"光斑"一词（工程层禁用），应换词表述为"面部一侧受光、另一侧渐变阴影"。**设计保留，换词表述。**

### 2. 全局优先级（高→低，规则冲突时高位胜出）
1. 台词完整性：零删减、不断裂
2. 全景/定位帧禁台词
3. 空间连续性：轴线、站位锁定、屏幕方向
4. 衔接连续性：动势、情绪、外观状态
5. 提示词禁用词与字数预算
6. 画幅与安全区
7. 节奏约束：段时长、单镜时长、台词字数区间
8. 镜头设计偏好：运镜多样性、景别丰富度、首帧换人
9. 光效风格偏好

### 3. 专项仲裁条款 ⚠️（逐条消除规则对撞）

| 冲突场景 | 仲裁结果 |
|---|---|
| 集首段：钩子帧 vs 新场景全景开场 | **钩子帧先行**（1-2镜），全景紧随其后交代空间（冷开场语法） |
| 换场景段：全景开场 vs 首帧换人 | **全景开场胜出**；首帧换人规则仅约束同场景延续段 |
| 段末定位全景 vs 结尾镜头禁全景 | 定位帧是叙事结尾镜头**之后的附加帧**，不算结尾镜头、不参与下段承接判断；**集尾段豁免定位帧**（悬念帧必须是最后画面） |
| 单句台词>45字且不可断、不可删 | 该段标注"超长台词段"，时长允许上浮至18秒（管线支持时）；管线不支持则在自然语气停顿处跨段接续并标注"台词跨段接续"，由后期负责音频无缝拼接 |
| 动作豁免段/闪回段/定位帧 vs 台词密度底线 | 豁免，不受"每段≥2句台词"与20字下限约束 |
| 打光设计用词 vs 禁用词表 | 设计保留，**换词表述**（禁用词表优先于一切光效表述） |
| 单人独白戏：首帧换人无人可换 | 首帧用道具/手部/背影/环境局部镜头替代 |

### 4. 模型版本复审注记
工艺层规则基于当前主流图生视频模型能力设定，应随模型迭代定期复审：
- 对口型能力提升 → 可放宽说话时景别限制
- 多人同框稳定性提升 → 可放宽全景崩脸缓释要求
- 多镜头时序支持增强 → 可调整生成管线选择

## 一、开工前置：画幅声明与全局资产表

### 1. 画幅声明 ⚠️ 开工必须先定
- **默认 9:16 竖屏**（用户声明横屏则按 16:9 执行，并恢复横屏语法）
- **竖屏构图规范**：
  - 单人构图优先，人物占画面主导
  - 纵向三层调度：前景元素压底边 / 人物中层 / 环境顶层——**用纵深替代横向调度**
  - 头顶留白适度，避免大面积空顶
  - **对话戏用单人正反打，不用过肩**（竖屏过肩肩膀占比过大）；可用前景虚化肩影暗示对方存在
  - **安全区**：画面右侧边缘约15%为互动按钮区、底部约20%为字幕/进度条区——人脸、手部关键动作、关键道具必须避开这两区
- 16:9 横屏时：恢复过肩镜头、三分法、横向调度等横屏语法

### 2. 全局资产表 ⚠️ 每个项目开工输出一次
开工先建表，后续每段只引用ID，不重复描述：

```
【角色表】角色ID | 姓名 | 参考图(有/无) | 性别 | 音色描述 | 打光缺省方案
【场景表】场景ID | 名称 | 参考图(有/无) | 内/外景 | 主光源清单(窗光/灯光/烛光/月光/霓虹等) | 色温基调
【道具表】道具ID | 名称 | 归属角色 | 参考图(有/无)
```

- **场景表的主光源清单是打光设计的依据**（见第十一章"光源动机"）
- 音色在角色表定义一次，段内不再重复输出
- 无参考图的资产 → 提示词中禁止描述其外观（见第十二章禁用词表）

### 3. 参考图优先级
**参考图 > 用户场景要求 > 无（无则不给外观/场景词）**
- 有参考图：按图实际画面描述服装/长相/场景，不得编造图中未呈现的内容
- 有场景要求无图：严格按场景要求生成，不添加用户未提及的元素
- 都没有：只写动作、情绪、运镜、光效、空间关系，**绝不自行编造任何外观/场景词**
- ⚠️ **剧本中的服装/长相描述一律不参考**——即使剧本写了"她穿着白色衣服"，提示词也不得引用（除非有参考图且与剧本一致）

### 4. 生成管线声明
- **默认管线**：图生视频，一段=一条提示词（含多镜头时序），首帧图=段首镜头静帧
- **分条管线**（用户声明或模型不支持多镜头时序时）：每镜头单独成条提示词，首尾帧接力；段级规则（站位/轴线/情绪衔接）仍跨条生效

## 二、剧作层：拆段与台词

### 1. 拆段基础规则
- 按剧情完整拆段，**不漏台词、绝不删减台词**
- 以约200字一段为基础参考
- 优先保证：台词不断裂、词气不断裂、动作承接不断裂、情绪落点不断裂
- **不允许为了凑字数硬拆完整表达**

### 2. 台词整合规则
- 单句台词超30字 → 按两句整合为一段
- 单句台词低于30字 → 按三句整合为一段
- 前提始终是：不能断裂台词、不能破坏完整表达、不能拆散与台词紧相连的动作和情绪

### 3. 台词字数规则 ⚠️ 核心规则（以15秒为单位）
- **每15秒台词不超过45字、不低于20字**（不含标点）
- 换算依据：中文常速约4-5字/秒，45字≈9-11秒台词，在15秒段内留足反应镜头与气口；20字下限防止凑时长拖节奏
- **⚠️ 绝不删减原剧本台词**——台词超标必须通过拆段控制，**为控制字数删减任何台词内容是严格禁止的**
- 拆段时注意：台词不断裂、词气不断裂、动作承接不断裂、情绪落点不断裂
- 单句>45字且无法拆分时 → 按专项仲裁条款处理（超长台词段）
- 拆段后在剧本内容栏附注字数统计（如：台词字数统计：42字，段时长14秒，符合15秒内20字≤台词≤45字）
- 豁免：动作豁免段、闪回段、定位帧不受20字下限约束

### 4. 闪回规则
- 遇到"闪回"字样 → **必须单独成段**
- 闪回段豁免台词密度底线；无台词闪回按纯动作段时长控制（≤4秒，镜头≤2个）

### 5. 台词密度底线 ⚠️
- **每段至少2句台词**（硬性底线，豁免段除外）
- 仅1句台词的段落 → 总时长≤6秒，镜头≤3个（尽量合并到相邻段）
- 纯动作/无台词段落 → 总时长≤4秒，镜头≤2个（**动作豁免段除外**，见下条）
- 台词不足2句时的补足方式：①合并相邻短段 ②拆段时主动将有台词的相邻内容归入同一段

### 6. 动作戏豁免条款 ⚠️ v2.0新增
- 打戏/追逐/坠落/仪式等**无台词动作段**：允许 6-15 秒、2-6 个镜头，不受台词密度约束
- **必须写出动作编排**：招式过程/攻防节奏/受击反应/环境互动，不允许"两人打斗"一笔带过
- 跟拍、急推急拉、环绕等辅助运镜在动作豁免段解禁为主力
- 动作豁免段前后必须有台词段衔接，不允许连续多个无台词段

## 三、空间系统：轴线、站位、视线 ⚠️ v2.0核心新增章节

### 1. 轴线规则（180°规则）⚠️ 空间第一规则
- **每场戏开场即建轴**：以核心两人连线（对话戏）或运动方向（动作戏）为轴线，**全场机位锁定在轴线一侧**
- **每个镜头必须标注屏幕方向**：人物位于画左/画中/画右 + 面朝画左/画右
- **对话正反打方向锁定**：A居画左面朝画右 ↔ B居画右面朝画左，全场保持不变
- **越轴管理**：确需越轴时，必须通过以下三者之一过渡，禁止硬越轴：
  1. 沿轴中性镜头（人物正面/正背面机位）
  2. 人物走位带轴（镜头跟随人物移动自然过轴，越轴后新轴线立即锁定并标注）
  3. 无方向性插入镜头（道具/手部特写）
- **30°规则**：同一主体相邻两个镜头，机位角度变化须≥30°或景别变化≥一级，否则视为跳剪
- **AI落地写法**：提示词中明确写"XX位于画面左侧、面朝画面右侧"——这是防止AI生成方向翻转的唯一手段，每镜必写

### 2. 位置锁定规则
- **所有人位置锁定**：每段的人物站位必须与上段末尾完全一致
- 不允许擅自移动未发生走位动作的角色；位置变化必须由剧本明确动作支撑
- 走位变化必须精确写出新位置（相对空间坐标），下一段首帧和空间关系栏必须精确定位到走位后的最新位置
- **后退半步也算位置变动**
- 人物从蹲/坐/跪等低位起身后，必须精确写出站起后的位置，该位置一旦确定，后续所有段落严格连续承接

### 3. 每段站位描述六要素
必须写清楚：左侧 / 中间 / 右侧 / 前景 / 后景 / 中轴关系
**不允许写"同上站位"、"站位不变"等**

### 4. 视线关系位
每段都必须写：
- 角色A看向谁、角色B看向谁
- 是否形成对视、视线是否对上
- ⚠️ 视线朝向必须与轴线栏的屏幕方向一致（A面朝画右看B，则B必在A的画右方向）

### 5. 动势衔接规则 ⚠️
- **所有人物的姿态变化必须有过渡过程**，不允许姿态突然跳变
- 坐→站必须写"撑桌起身""缓缓站直"等过渡动作；跪→站、站→蹲、蹲→趴等同理
- 姿态变化前必须有动势铺垫（身体前倾、重心转移、手部支撑等）
- **⚠️ 前后段动势丝滑衔接**：下一段首帧人物的姿态、动作方向、身体朝向必须严格承接上一段末帧状态，不允许动作断点、姿态跳变、方向突变
- **⚠️ 动势衔接自检**：写完每段必须回顾上一段末帧人物状态，确认当前段首帧完全匹配，无割裂感

## 四、人物状态与表演

每段都必须补：
1. **实际出场人物**
2. **人物特殊道具**（明确哪只手拿道具）
3. **人物姿态状态**：站、跪、跌坐、俯身、缓步前行、抬手、转身、前倾、后仰、低头、抬眼等
4. **人物情绪状态**：情绪必须明确，动作必须服务情绪

### 站桩禁止 ⚠️ 核心规则
- **绝对不允许站桩式念台词**，禁止人物反应呆板
- **人物一旦入镜必有反应**——无论是否当前说话者，入镜即须有符合场景情绪的表情反应或肢体微动作
- 角色说台词时，必须伴随**手部动作和表情变化**；部分剧情可增加走位
- 台词必须挂在动作和情绪上完成表达
- **避免死脸**：背景人物/旁观者也必须呈现与场景氛围一致的表情状态（紧张场景不能淡定，悲伤场景不能微笑）

### 外观状态连续性 ⚠️
- **人物外观状态必须全程连续**：被水泼湿、出汗、受伤流血、泥土沾面、衣衫破损等状态变化，从发生起，**后续所有段落所有镜头必须保持该状态描述**
- 状态持续到剧本明确发生消除该状态的动作
- **每段人物道具姿态栏必须复述当前持续中的外观状态**，不允许凭空消失或时有时无

### 情绪衔接规则 ⚠️
- **同场次人物情绪全程连贯递进，不得有任何割裂感**：不允许前一段愤怒、下一段若无其事
- 情绪转折必须由剧本台词/动作支撑，不可自行跳变
- 旁观角色情绪反应必须与当前场景情绪一致
- **⚠️ 前后段情绪丝滑衔接**：下一段首帧情绪必须严格承接上一段末帧情绪落点
- **⚠️ 情绪过渡必须有载体**：情绪从A转B时，必须通过台词、动作、表情、呼吸等具体载体呈现过渡，不可凭空跳变
- **⚠️ 情绪衔接自检**：写完每段回顾上一段末帧情绪落点，确认当前段首帧完全匹配

## 五、节奏与景别

### 时间约束
- **常规单镜2-4秒**（最长不超过4秒）
- **反应镜头/插入镜头允许1-2秒**（明确例外）
- **全景/定位帧≤2秒**
- 每段总时长：根据台词量灵活调整，**最长不超过15秒**（超长台词段例外，≤18秒）
- **台词少的段落要短！不要凑时长！**
- 段时长参考梯度：
  - 仅1句台词 → 4-6秒，2-3个镜头（尽量合并到相邻段）
  - 台词少（2句）→ 6-8秒，3-4个镜头
  - 台词中等（3-4句）→ 10-12秒，4-5个镜头
  - 台词多/情绪爆发 → 12-15秒，5个镜头
  - 动作豁免段 → 6-15秒，2-6个镜头
- 禁止长镜头：连续相同运镜方式=视觉长镜头，必须避免

### 景别规范 ⚠️ v2.0修订
- 常规景别：全景 / 中景 / 中近景 / 近景
- **⚠️ 说话期间禁止胸部以上特写（对口型规避）——硬规则，无例外**
- **⚠️ 条件许可面部特写**（v2.0新增）：同时满足以下三条 → 允许胸部以上面部特写，每段≤1个，1-2秒：
  1. 非说话时刻（无对口型需求）
  2. 该角色有定妆参考图（一致性有保障）
  3. 情绪爆点/关键反应瞬间
- **无参考图角色：维持禁特写**（一致性风险不可控）
- 眼睛/嘴巴大特写：**高风险选项**（画幅越紧越易崩），仅在有强参考图且确属情绪顶点时使用，使用频率应低于常规面部特写

### 焦段表 ⚠️ v2.0新增

| 景别 | 推荐焦段 | 说明 |
|------|----------|------|
| 全景/定位帧 | 24-35mm | 空间交代 |
| 中景 | 35-50mm | 调度主力 |
| 中近景 | 50-85mm | 对话主力 |
| 近景 | 85mm | 压缩背景、浅景深 |
| 面部特写（条件许可） | 85-105mm | 必须背景虚化 |

- 广角贴近人物产生畸变，仅用于压迫/眩晕/失衡的刻意表现，不得常规使用

### 景别丰富度
- **必须使用多种景别**，避免连续相同景别
- 景别变化要有逻辑（情绪递进、空间转换等），并遵守30°规则防跳剪

## 六、镜头与运镜 ⚠️ 核心章节

### 1. 切镜规则 ⚠️
- **切镜头直接切，绝对不能用运镜方式切换镜头**
- **运镜仅作用于单个镜头内部，绝不允许用于镜头间过渡**
- 禁止：❌甩镜切 ❌推进切 ❌拉远切 ❌平移切 ❌任何以运镜运动替代切镜的衔接
- 每个镜头内部的运镜在该镜头内完成，然后直接切到下一镜头

### 2. 动势原则 ⚠️ v2.0核心修订
- **每个镜头必须有"动势"——镜头运动或画内主体运动，至少其一**
- **定镜许可**：定镜（固定机位）+ 明显画内动势 = 合法镜头
  - 适用场景：对峙僵持、权威感、构图压迫、惊愕定格、收束留白
  - 画内动势可以是：人物动作、表情变化、呼吸起伏、环境元素运动（风吹、光影移动、雨落）
  - **定镜占比建议≤30%**，运动镜头仍为主体（保留短剧流动感）
- **绝对禁止：定镜 + 人物静止无表演 = 冻结帧**（这才是真正要防的东西）

### 3. 运镜分级 ⚠️ v2.0修订
- **主选（优先使用）**：
  - **左右平移**（流动感与空间层次）
  - **缓慢推进**（聚焦情绪，推进终点不小于近景底线）
  - **拉远**（疏离、释然、空间展开）
  - **定镜+画内动势**（对峙、凝滞、权威）
- **辅助（剧情需要时使用）**：
  - **旋转摇上/旋转摇下**——⚠️ v2.0降级为辅助：roll+tilt复合运动AI易崩且语感重，**每段≤1次、速度≤匀速，留给情绪转折点**
  - 升镜/降镜、半环绕、跟拍（动作/追逐专用）、急推/急拉（爆点专用）、纵深推进、低角度贴地、俯拍/上帝视角
- **慎用**：全环绕（AI极易崩）
- **禁止**：甩镜
- **多样性规则**：
  - **连续两镜不得使用相同运镜（硬规则）**
  - 单一运镜方式占比参考上限40%（指导值，不做机械配额）
  - **运镜选择以"表达什么"为准，禁止为凑占比机械轮换**

### 4. 运镜配合情绪与台词 ⚠️
- 情绪递进时运镜加速或推进；情绪沉落时放缓或拉远
- 台词节奏快慢与运镜速度匹配
- 关键台词/情绪转折点运镜要有对应变化（急推、旋转摇上、或转为定镜凝滞）
- **镜头语言对照**：推进=压迫聚焦 / 拉远=疏离释然 / 升镜=升华力量 / 降镜=沉重无力 / 平移=观察流动 / 急推急拉=震惊爆发 / **定镜=对峙凝滞威压**
- 每个运镜选择必须能回答"这个运镜在表达什么"

### 5. 运镜场景对照表

| 剧情场景 | 推荐运镜方式 | 推荐速度 |
|----------|--------------|----------|
| 交代环境/空间关系 | 全景缓推、俯拍、升镜拉远 | 缓慢 |
| 氛围铺垫/情绪酝酿 | 缓慢推进、左右平移、定镜+画内动势 | 缓慢 |
| 紧张对峙/冲突升级 | 定镜凝滞、推进、平移、斜切 | 匀速至快速 |
| 动作场面/情绪爆发 | 跟拍、急推、环绕（豁免段解禁） | 快速 |
| 对话交流/信息传递 | 单人正反打+微平移、缓慢推进、反应镜头 | 匀速 |
| 高潮/逆转/关键瞬间 | 急推、急拉、旋转摇上（每段≤1次） | 快速 |
| 结尾收束/悬念留白 | 缓慢拉远、定镜+画内动势、旋转摇下 | 缓慢 |
| 单人独白/内心戏 | 缓慢推进、微平移、定镜 | 缓慢 |
| 人物出场/登场 | 推进、纵深推进、低角度 | 匀速 |
| 情感转折/心绪变化 | 推进转拉远、升降、由动转定 | 由缓转匀 |

### 6. 运镜速度标注规范
每条运镜必须标注速度，格式：`运镜方式（速度）`
- 缓慢：氛围铺垫、情绪酝酿、回忆思念、结尾留白
- 匀速：对话推进、信息传递、人物出场、日常场景
- 快速：情绪爆点、冲突对峙、动作场面、卡点反转
- ⚠️ 旋转类运镜速度≤匀速

### 7. 气口与声桥 ⚠️
- **留1秒气口**：最后一句台词结束后，留至少1秒画面延续（表情反应、动作延续、环境呼吸），不让台词卡着时间线尾巴结束（卡尾帧会吃字）
- **声桥提示（v2.0新增，可选）**：气口处可在"后期备注"栏标注：
  - J-cut：下段首句台词预压入本段气口
  - L-cut：本段环境音延入下段开头
  - 仅作为后期剪辑备注，**不写入提示词正文**

### 8. 每条运镜必须包含
景别（焦段）/ 运镜方式（速度）/ 构图方式 / 镜头语言（表达什么）/ 人物表情情绪 / 人物动作 / **屏幕方向与视线** / 空间关系 / **[光效]标记**

### 9. 构图类型（按画幅适配）
- 竖屏主力：纵深引导线、前景压边（压底边）、高低位压迫、中心压迫、人物偏置、上下分层
- 横屏补充：对角线、三分法、左右对峙、过肩构图
- ⚠️ 构图必须与已声明画幅匹配

## 七、全景与站位定位帧 ⚠️ v2.0重构

### 1. 全景禁台词 ⚠️ 绝对规则（优先级第2位）
- **全景/定位帧中不允许任何角色说话、OS、VO或画外音**——进入全景镜头，所有声音通道静默
- 如果台词未说完，先完成台词再出全景

### 2. 新场景全景开场
- **新场景首次出现时必须以全景开场**，先交代完整空间环境，再切入人物（集首段钩子帧例外，见仲裁表：钩子先行、全景随后）
- **⚠️ 多人全景崩脸缓释（v2.0新增）**：多人全景是AI崩脸最高发镜头，必须做缓释——优先用**背影机位/高机位俯拍/剪影/拉开距离降低面部像素占比**，避免多人正脸全景

### 3. 站位定位帧 ⚠️ v2.0新概念（替代"段末全景"）
- **定义**：叙事结尾镜头**之后的附加帧**，≤2秒，无台词，轻微运镜或画内动势，功能是向后续段落的生成提供站位参考
- **触发条件**：
  1. 第一段结尾（看清所有人初始站位）
  2. 任何人物位置/姿态/面朝方向发生变化的段末
  3. 无变化不出（避免每段都出导致冗余）
- **豁免**：集尾段不出定位帧（悬念帧必须是最后画面）
- **性质判定**：定位帧不算结尾镜头、不参与首帧换人判断（消除v1.2"段末全景vs结尾禁全景"死锁）
- 定位帧同样适用多人崩脸缓释（背影/高机位/剪影）

### 4. 推进剧情的全景
- 全景用于展示走动/位移等动态过程（追逐、入场、离场）时允许推进剧情，**但必须搭配运镜**（跟拍推进/平移跟拍/升镜俯拍），纯静止全景不得推进剧情

## 八、首帧与结尾镜头 ⚠️ v2.0重构

### 1. 首帧优先级（从高到低，取第一个命中项）
1. **集首段** → 钩子帧（全剧最强冲突/悬念/高情绪画面）
2. **新场景段** → 全景开场（含多人崩脸缓释）
3. **同场景延续段** → 换人：首帧为上一段叙事结尾镜头人物**以外**的角色
4. **单人戏** → 道具/手部/背影/环境局部镜头替代
- 对话戏延续段：竖屏从单人正反打开始（横屏可从过肩开始）
- 首帧即图生视频的种子帧，必须描述精确（人物、姿态、屏幕方向、景别、光效）

### 2. 结尾镜头规则
- **叙事结尾镜头禁全景**；可以是：中景、中近景、近景、道具镜头、人物反应镜头、环境局部镜头
- 结尾镜头必须服务下一段承接；**下一段首帧不得从该人物开始**（同场景延续时）
- 段末如触发定位帧，定位帧附加在叙事结尾镜头之后（见第七章）
- **集尾段：结尾镜头=悬念帧**（见第十章）

---

## 九、反应镜头规则

- 人物说话时，**必须给其他重要角色的表情反应镜头**，避免站桩说话
- **重点情绪台词处**，必须给到其他人的表情反应镜头
- **⚠️ 人物一旦入镜必有反应**——画面中出现的人物不能是木偶状态，必须有与场景情绪一致的微表情/微动作
- 反应镜头以近景/中近景为主，时长1-2秒（单镜时长例外条款），必须搭配运镜或画内动势（微平移/微推进/定镜+表情变化）
- **所有人说话不要正对镜头说话**；可以正面、侧面、转身背面拍摄
- 说话期间严禁胸部以上特写（对口型规避），景别最小近景

## 十、集级结构与钩子帧 ⚠️ v2.0新增

分镜层的钩子责任 = **选帧**：同样的剧本内容，开场选最强画面、结尾选最吊画面。

- **集首段**：第一镜=钩子帧——把全集最强冲突/悬念/高情绪画面调度到开场前3秒；允许冷开场（钩子先行、全景随后交代空间）
- **集尾段**：结尾镜头=悬念帧——反转揭示/危机定格/情绪顶点；禁全景、禁定位帧冲淡（集尾豁免定位帧）
- **付费卡点**：用户标注卡点段时，该段按集尾段标准执行，收在最强悬念帧
- 用户未提供分集信息时，按单集处理：首段执行集首规则、末段执行集尾规则

## 十一、光效与打光 ⚠️ v2.0重构

### 1. 打光决策顺序 ⚠️（依次判断，高位优先）

**第一步：光源动机（motivated lighting）**
- 查场景表主光源清单，**主光方向/性质必须能被场景内光源解释**（窗光/灯光/烛光/月光/霓虹/天光）
- 提示词写明光从哪来（如"暖黄灯光从画右侧上方照下"）

**第二步：情绪反差**
- 冲突/压迫 = 硬光高反差
- 温情/日常 = 柔光低反差
- 审判/压抑 = 顶光
- 恐惧/不安 = 低位光
- 悬疑/撕裂 = 侧光分割（半明半暗）

**第三步：缺省方案**（无明确光源依据与情绪指向时才使用）
- 男性 = 侧光塑形（伦勃朗式）——提示词表述为**"面部一侧受光、另一侧渐变阴影、立体硬朗"**，⚠️不得写"三角光斑"
- 女性 = 柔和顶前光（蝴蝶式）——提示词表述为**"正面柔光、面部立体柔美"**，⚠️不得写"蝴蝶阴影/光斑"
- ⚠️ 性别打光仅是缺省值：悲情/惊悚/崩溃戏的女性角色应按情绪反差打光，不得机械套用美颜光

**第四步：轮廓光**
- 近景/中近景/氛围镜头**默认侧逆光勾边**，将人物与背景分离——**前提是场景存在可解释的背光源**（窗、灯、天光、月光）
- 光源逻辑不成立时（如正午顺光外景），**改用色彩分离/景深分离**实现人物背景分离，不强行逆光

### 2. 色温规则
- **同场次色温必须统一**，不可忽冷忽暖
- 场次间题材氛围转变时，色温通过过渡段逐步转换，不可硬切
- **逆光色温必须与主光色温一致**（暖调题材逆光也是暖色）

### 3. 题材冷暖光对照表

|----------|----------|------------|----------|
| 古装/宫廷/武侠 | 暖金色（2800K-3500K） | 温润厚重、古典韵味、烛火暖调 | 暖金勾边 |
| 古装/悲情/权谋 | 冷青蓝（4500K-5500K） | 清冷肃杀、阴暗压抑、月光银灰 | 冷蓝勾边 |
| 现代/都市/爱情 | 暖白柔光（3500K-4200K） | 温馨柔和、日常质感、自然通透 | 暖白勾边 |
| 现代/悬疑/犯罪 | 冷蓝灰（5000K-6500K） | 冷硬疏离、霓虹质感、暗调低饱和 | 冷蓝/冷白勾边 |

### 4. 丁达尔光
- **按剧情需要设定，不得滥用**：仅在有明确光线穿过微粒的场景使用（窗光射入烟尘、森林晨雾光束、烛烟光线），普通无微粒场景禁止添加

| 旁白/画外音/黑屏 | — | — | 永不解除 |

⚠️ **再次强调分层认知**：禁用词约束写法不约束设计——伦勃朗式塑形照打，但写成"一侧受光一侧渐变阴影"；人物眼睛照样有神，但提示词里一个"眼神光"都不出现。

### 2. 字数预算 ⚠️ v2.0修订
- **1900字上限只计提示词正文**：画面视觉基调（[光效]展开后）+ 分秒运镜提示词 + 特效提示词
- **不计入**：场景栏、轴线栏、站位栏、视线栏、道具姿态栏、剧本内容、音效建议、字数统计注记、后期备注（这些是执行稿元信息，不喂给视频模型）
- [光效]宏在写作时缩写、交付时展开，展开后字数计入预算

### 3. 交付物性质声明
- 成品执行稿 = **干声纯画面执行稿**：无字幕、无BGM、无旁白
- ⚠️ 这是交付物规格，**不代表成片无BGM/字幕**——BGM、台词字幕由后期统一添加；规则约束的是生成画面内不得自带这些元素

## 十三、声音与特效

### 1. 特效提示词
- 特效必须服务剧情，和人物动作、环境反馈、镜头变化同步，必须写成可视化内容

### 2. 音效建议（与运镜联动）
- 环境音 / 动作音 / 道具音 / 特效音 / 情绪增强音
- 情绪增强音指音效性质的单点强调音（心跳声、耳鸣声、钟摆声），不得演变为旋律性BGM

### 3. 后期备注栏（v2.0新增，可选）
- 声桥提示（J-cut/L-cut）
- BGM情绪方向建议（仅方向词，如"压抑弦乐方向"，供后期参考，不写入任何画面/提示词内容）
- 字幕由后期统一添加的提醒

### 4. 音色
- 在全局资产表角色表中定义一次，段内不再重复

## 十六、执行口诀（丹姐6月 v2.0版）

**总纲**：三层分明——剧作管演什么、视听管怎么拍、工程管怎么写；冲突看仲裁表，高位胜出

**开工**：先定画幅（默认9:16竖屏）、先建资产表（角色/场景/道具/光源清单）、先声明管线，每段只引用ID

**拆段**：按剧情完整拆段，不漏不删台词；每15秒台词20-45字（常速4-5字/秒），超标拆段、不足合并，绝不删词；超长单句走仲裁条款；附字数统计

**轴线**：每场建轴、机位锁定一侧；每镜标注画左画右与面朝方向；越轴必走合法过渡（中性镜头/走位带轴/无方向插入）；同主体相邻镜遵守30°规则

**位置**：所有人位置锁定，与上段末尾完全一致；后退半步也算变动；站位六要素全写、禁"同上"

**动势衔接**：姿态变化必有过渡动作；前后段首末帧姿态/朝向/情绪丝滑承接，过渡必有载体

**切镜**：直接切；运镜只在镜头内部，绝不做转场；禁甩镜

**镜头动势**：每镜必有动势——运镜或画内运动至少其一；定镜+画内动势合法（≤30%），定镜+静止=冻结帧（禁止）；连续两镜不同运镜；旋转摇每段≤1次速度≤匀速；运镜以"表达什么"为准、禁机械轮换

**景别**：全中近为主、每镜标焦段；说话期间禁胸上特写（硬规则）；非说话+有参考图+情绪爆点=允许面部特写（每段≤1个）；无参考图维持禁特写

**全景**：禁台词（绝对规则）；新场景全景开场（集首让位钩子帧）；多人全景必做崩脸缓释（背影/高机位/剪影）；≤2秒、必有动势

**定位帧**：叙事结尾镜头之后的附加帧；第一段结尾、位置/姿态/方向变化后触发；无变化不出；集尾豁免；不算结尾镜头

**首帧**：集首钩子帧 > 新场景全景 > 同场景换人 > 单人戏替代帧（道具/手部/背影）

**结尾**：叙事结尾禁全景、服务承接；集尾段收悬念帧、付费卡点同理

**反应**：说话给他人反应；入镜必有反应、禁木偶死脸；不正对镜头说话

**打光**：光源动机第一（查场景表光源清单）、情绪反差第二、性别缺省第三；近景默认侧逆光勾边但须光源成立，不成立改色彩/景深分离；同场色温统一、按题材冷暖表调配；丁达尔仅微粒场景

**禁用词**：眼神光/面部光斑永不写（设计保留、换词表述）；无参考图不写服装长相场景词；剧本外貌描述一律不参考；画面无文字无字幕；无BGM无旁白（干声交付，后期统一加）

**字数**：1900字只计提示词正文（基调+运镜+特效），元信息不计；[光效]交付时展开

**气口**：最后一句台词后留≥1秒气口；可标注J/L声桥供后期

**豁免**：动作戏6-15秒解禁跟拍急推（必写动作编排）；闪回单独成段；豁免段不受台词密度约束

**自检**：先过🔴阻断项（12条，违一不出稿），再过🟡质量项（20条）
