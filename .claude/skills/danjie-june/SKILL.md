# 丹姐6月 v2.3 - AI短剧分镜执行技能

> 小说/剧本 → 短视频分镜执行稿
> 核心能力：拆段、轴线、运镜、光效、特效、音效全链路输出
> v2.2 修订要点：吸收物理仿真推演派精华并经三层仲裁消化——景别细节粒度分级、拆段四断点、负载分级、反穿模借位、真空期补帧、表情过程化、空间高低/距离/遮挡维度、视线落点系统、闪回闭环、文字定妆锚点、涟漪效应、音效张力三件套、空镜规范、内心OS开关、一镜到底段开关

## 〇、三层规则体系与优先级仲裁 ⚠️ 全文总纲（先读本章）

### 1. 三层规则体系
本技能所有规则分属三层，遇到表述冲突先判断所属层：

- **剧作层**：台词、剧情、拆段——管"演什么"
- **视听语法层**：轴线、景别、运镜、打光设计、节奏——管"怎么拍"
- **提示词工程层**：禁用词、字数预算、参考图、防伪影——管"怎么写给模型"

⚠️ **关键认知**：提示词工程层的禁用词约束的是**写法**，不约束视听设计本身。
例：打光设计可以采用伦勃朗式侧光塑形（视听层成立），但提示词中不得出现"光斑"一词（工程层禁用），应换词表述为"面部一侧受光、另一侧渐变阴影"。**设计保留，换词表述。**

### 2. 全局优先级（高→低，规则冲突时高位胜出）
1. 台词完整性：零删减、不断裂；剧情零压缩（回忆/长动作禁梗概化）
2. 全景/定位帧禁台词
3. 空间连续性：轴线、站位锁定、屏幕方向、出入画方向、高低与距离真实性
4. 衔接连续性：动势、情绪、人物外观状态、环境道具状态
5. 提示词禁用词与字数预算
6. 画幅与安全区
7. 节奏约束：段时长、单镜时长（按负载分级）、台词字数区间、时间轴核算
8. 镜头设计偏好：运镜多样性、景别丰富度、首帧换人
9. 光效风格偏好

### 3. 专项仲裁条款 ⚠️（逐条消除规则对撞）

| 冲突场景 | 仲裁结果 |
|---|---|
| 集首段：钩子帧 vs 新场景全景开场 | **钩子帧先行**（1-2镜），全景紧随其后交代空间（冷开场语法） |
| 换场景段：全景开场 vs 首帧换人 | **全景开场胜出**；首帧换人规则仅约束同场景延续段 |
| 段末定位全景 vs 结尾镜头禁全景 | 定位帧是叙事结尾镜头**之后的附加帧**，不算结尾镜头、不参与下段承接判断；**集尾段豁免定位帧** |
| 单句台词>45字且不可断、不可删 | 该段标注"超长台词段"，时长允许上浮至18秒（管线支持时）；管线不支持则在自然语气停顿处跨段接续并标注，由后期负责音频无缝拼接 |
| 动作豁免段/闪回段/定位帧 vs 台词密度底线 | 豁免，不受"每段≥2句台词"与20字下限约束 |
| 拆段四断点 vs 台词密度底线 | **断点强制性高于密度底线**——触发断点必须拆段，拆出的短段按短段时长规则执行（1句≤6秒），不得为凑台词跨断点合并 |
| 打光设计用词 vs 禁用词表 | 设计保留，**换词表述** |
| 单人独白戏：首帧换人无人可换 | 首帧用道具/手部/背影/环境局部镜头替代 |
| 声音三态判定（v2.2） | **画外台词=合法**：场景内角色当前时空的现场说话声；**内心OS=开关**：角色当下内心声音，默认关闭、用户声明启用后合法且必须双轨绑定；**解说旁白=永禁**：叙述者/事后解说声 |
| 连续相同运镜禁令 vs 正反打定镜对切 | 正反打定镜对切合法（不同机位即不同镜头），不受连镜禁令限制；**运动运镜**仍不得连续同型同向 |
| 入镜必有反应 vs 远景禁微表情（v2.2） | 反应的**颗粒度按景别分级**：远景/全景中"宏观肢体势态"即为合格反应，不写五官；微表情仅特写/近景层级要求 |
| 一镜到底段 vs 切镜规则（v2.2） | 用户声明的一镜到底段**豁免切镜规则与单镜时长限制**，段内以连续运镜调度替代切镜；轴线、状态连续、台词规则照常生效 |
| 文字定妆锚点 vs 无图禁外貌词（v2.2） | 资产表统一定义的**文字定妆词组是禁令的唯一例外**（全剧逐字复用、不得变体）；逐段临时编造外貌词仍然严禁 |

### 4. 模型版本复审注记
工艺层规则基于当前主流图生视频模型能力设定，应随模型迭代定期复审：对口型能力提升→放宽说话景别与画外台词占比；多人同框稳定→放宽全景与群演缓释；多镜头时序增强→调整管线选择。

## 一、开工前置与执行流程

### 1. 执行流程总览 ⚠️ 六步SOP
```
①读本通读 → ②建全局资产表 → ③出节拍与拆段规划表（用户确认）
→ ④逐段产出执行稿 → ⑤每段过分级自检（🔴阻断→🟡质量）→ ⑥交付（资产表+规划表+全部段落+集末状态快照）
```
- ③规划先行：先定全局节奏与时长预算，避免写到一半节奏失衡推倒重来
- 局部返工：单镜头生成失败时按镜头粒度重出，不牵连整段

### 2. 画幅声明 ⚠️ 开工必须先定
- **默认 9:16 竖屏**（用户声明横屏则按 16:9 执行，并恢复横屏语法）
- **竖屏构图规范**：
  - 单人构图优先，人物占画面主导
  - 纵向三层调度：前景元素压底边 / 人物中层 / 环境顶层——**用纵深替代横向调度**
  - 头顶留白适度，避免大面积空顶
  - **对话戏用单人正反打，不用过肩**；可用前景虚化肩影暗示对方存在
  - **安全区**：画面右侧边缘约15%（互动按钮区）、底部约20%（字幕/进度条区）——人脸、手部关键动作、关键道具避开
- 16:9 横屏时：恢复过肩镜头、三分法、横向调度等横屏语法

### 3. 全局资产表 ⚠️ 每个项目开工输出一次
开工先建表，后续每段只引用ID，不重复描述：

```
【角色表】角色ID | 姓名 | 性别 | 音色描述 | 打光缺省方案
  └ 造型变体：造型ID(A/B/C…) | 一致性锚点：参考图(有/无) 或 文字定妆词组 | 适用场次范围
【场景表】场景ID | 名称 | 内/外景 | 主光源清单 | 主光方向(画左/画右/顶/背) | 色温基调
  └ 时段变体：时段ID(日/夜/黄昏…) | 参考图(有/无) | 光线状态
【道具表】道具ID | 名称 | 归属角色 | 参考图(有/无)
【全局开关】内心OS：关(默认)/开 ｜ 闪回编码：色温偏移/降饱和(二选一) ｜ 风格：写实(默认)/其他
```

- **文字定妆锚点（v2.2新增）**：无参考图的角色/场景，可在资产表定义**固定外貌/服装/场景锚定词组**（每项30-60字、精炼），由用户提供或经用户确认后从剧本提炼；启用后**全剧逐字复用、不得改写变体**——这是"无图禁外貌词"禁令的唯一例外，逐段临时编造仍然严禁
- **一致性锚点优先级：参考图 > 文字定妆词组 > 无（无则不写外观）**
- **造型变体**：换装必须有剧本支撑（换场/换日/明确换装动作），每段引用"角色ID-造型ID"，同场次内锁定不得漂移
- **时段变体**：同场景昼夜按时段ID区分，时间跳跃按换场处理
- 场景表的主光源清单与主光方向是打光设计依据（见第十一章）
- 音色在角色表定义一次，段内不再重复

### 4. 节拍与拆段规划表 ⚠️ 逐段产出前必须先出
```
【节拍规划表】集数 | 段号 | 一句话内容 | 段类型 | 负载判定 | 时长预算 | 场景ID-时段 | 出场角色-造型 | 钩子/反转/卡点标记
```
- **集时长预算**：默认单集成片60-120秒≈5-8段（按用户平台要求调整），先分预算再写稿
- 全剧反转点、情绪顶点、付费卡点标记完毕后再逐段执行；规划表建议用户确认后批量产出

### 5. 参考图与定妆优先级
**参考图 > 文字定妆词组 > 用户场景要求 > 无（无则不给外观/场景词）**
- 有参考图：按图实际画面描述，不得编造图中未呈现内容
- 有文字定妆：逐字引用锚定词组，不得变体、不得扩写
- 有场景要求无图：严格按要求生成，不添加未提及元素
- 都没有：只写动作、情绪、运镜、光效、空间关系
- ⚠️ **剧本中的服装/长相描述不得逐段直接引用**——但可作为建立文字定妆词组的素材（须经用户确认固化进资产表）

### 6. 生成管线声明
- **默认管线**：图生视频，一段=一条提示词（含多镜头时序），首帧图=段首镜头静帧
- **分条管线**：每镜头单独成条，首尾帧接力；段级规则仍跨条生效
- **段间接力**：同场景延续段，上段末帧（或定位帧）作为下段首帧图的空间参考底图

## 二、剧作层：场次、拆段与台词

### 1. 场次规则 ⚠️
- 一切按剧本场次和场景来，**一段只属于一个场次**
- 场次/场景切换必须同步拆段，**不允许自行更改剧本场景设定**
- **同场景内时间跳跃**按换场处理：拆段 + 时段变体 + 光线同步更新 + 后期备注时间转场
- **平行剪辑**：按线分段交替输出，每条线独立遵守轴线、站位、状态连续

### 2. 拆段四断点 ⚠️ v2.2核心升级（优先切分依据）
拆段以下列四个断点为**优先依据**，约200字一段降为辅助参考。触发任一断点，必须切分为新段：
1. **时空跃迁断点**：空间改变（室内→室外、A地→B地）或时间流逝（深夜→清晨、三天后）——即场次规则
2. **微目标转换断点**：角色核心动机突变。例：前段微目标是"试探对方底细"（文戏），突然"刺客破窗"（武戏）目标瞬变为"生存反击"——必须拆为两段
3. **阵营变动断点**：具有破局能力、能改变当前权力压迫关系的关键角色**入场或离场**（如绝境中救兵从天而降）——新人物介入是切分的绝对标尺
4. **情绪沉降断点**：激烈对抗或情绪爆发后的"余韵沉降期"（烟尘消散、脱力喘息）结束，即当前段完结；下一个动作的重新发起属于新段

### 3. 拆段基础规则
- 按剧情完整拆段，**不漏台词、绝不删减台词**
- **剧情零压缩（v2.2新增）**：回忆、前史、长动作段落**禁止压缩成一句话梗概**，必须完整拆解为镜头序列——保护范围从台词扩展到剧情动作层
- 优先保证：台词不断裂、词气不断裂、动作承接不断裂、情绪落点不断裂
- 不允许为了凑字数硬拆完整表达

### 4. 台词整合规则
- 单句超30字 → 按两句整合为一段；单句低于30字 → 按三句整合为一段
- 前提：不断裂台词、不破坏完整表达、不拆散与台词紧相连的动作和情绪

### 5. 台词字数规则 ⚠️（以15秒为单位）
- **每15秒台词不超过45字、不低于20字**（不含标点；启用内心OS时，OS计入字数统计）
- 换算依据：中文常速约4-5字/秒，45字≈9-11秒台词，留足反应与气口；20字下限防凑时长
- **绝不删减原剧本台词**——超标必须拆段，为控字数删词严格禁止
- 单句>45字无法拆分 → 按仲裁条款处理（超长台词段）
- 拆段后附注字数统计（如：台词字数统计：42字，段时长14秒）
- 豁免：动作豁免段、闪回段、定位帧不受20字下限约束

### 6. 闪回规则 ⚠️ v2.2强化
- 遇"闪回"→ **必须单独成段**，标注【闪回段】
- **三明治闭环（v2.2新增）**：现实 → 闪回 → **必须切回现实**，且切回后精准衔接角色因回忆产生的**情绪突变或动作前摇**，不允许闪回悬空收尾
- **闪回分型时长（v2.2新增）**：
  - 情绪闪现型（模糊面容/一句话）：1个镜头、1-2秒，瞬间切回
  - 叙事交代型（救命恩情/恩怨前史）：划拨足够时长，闪回内继续切分2-3个镜头完整叙事，**禁止压缩成梗概**
- **闪回完整性一票否决（v2.2新增）**：禁止把截断点落在闪回中——跨生成批次时闪回必须完整包含在同一批次内，绝不允许半截闪回留给下次
- **闪回视觉编码**：全剧统一一种标记（色温偏移或降饱和，写入资产表开关区），进出闪回直接切（可配回声音桥），白闪慎用；闪回内部照常遵守轴线与连续性
- 闪回段豁免台词密度；无台词闪回按纯动作段控制（≤4秒，≤2镜）

### 7. 台词密度底线 ⚠️
- **每段至少2句台词**（豁免段除外）
- 仅1句台词 → 总时长≤6秒，镜头≤3个；纯动作/无台词段 → ≤4秒，≤2镜（动作豁免段除外）
- 补足方式：①合并相邻短段 ②拆段时将有台词的相邻内容归入同段（不得跨四断点合并）

### 8. 动作戏豁免条款 ⚠️ v2.2强化
- 打戏/追逐/坠落/仪式等无台词动作段：允许 6-15 秒、2-8 个镜头（极高负载允许0.5-2秒急切，镜头数相应增加），不受台词密度约束
- **必须写出动作编排**：招式过程/攻防节奏/受击反应/环境互动，不允许"两人打斗"一笔带过
- **反穿模借位剪辑（v2.2新增，肢体接触强制执行）**：
  - **接触瞬间规避法**：镜头A展现发力起势（在身体接触前切出）→ 直接切 → 镜头B展现**受击结果**（受击者踉跄/倒飞/环境破坏），严禁用单一镜头完整呈现持续性肉搏接触过程
  - **前景遮挡借位**：利用飞扬尘土、门框、栏杆、衣摆、光效等前景物体遮挡易穿模的接触区；遮挡物不得改变主空间关系
- **涟漪效应（v2.2新增）**：大场面/大招/重击段落，**至少30%镜头给"环境破坏反馈"（碎石/气浪/震落的灰尘）或"旁观者惊恐反应"**——用旁观与环境反衬力量，禁止所有镜头死盯主体
- 跟拍、急推急拉、环绕在动作豁免段解禁为主力
- 动作豁免段前后必须有台词段衔接

## 三、空间系统：轴线、方向、站位、视线 ⚠️ 核心章节

### 1. 轴线规则（180°规则）
- **每场戏开场即建轴**：以核心两人连线（对话戏）或运动方向（动作戏）为轴，**全场机位锁定一侧**
- **每镜标注屏幕方向**：人物位于画左/画中/画右 + 面朝画左/画右
- 对话正反打方向锁定：A居画左面朝画右 ↔ B居画右面朝画左，全场不变
- **越轴管理**：仅可通过①沿轴中性镜头②人物走位带轴③无方向性插入镜头三者之一过渡，禁止硬越轴
- **30°规则**：同一主体直接相切的两镜，机位变化≥30°或景别变化≥一级
- **AI落地写法**：提示词明确写"XX位于画面左侧、面朝画面右侧"，每镜必写

### 2. 多人戏轴线与群演
- **三人以上**：核心冲突双方连线定**主轴**，第三方固定区域后按副轴处理；单人反应插入镜头维持其在主轴侧的既有朝向
- **群演崩脸缓释**：背景群演不给正脸——虚化、背影、肩部以下、远景化任选；人数在段落标注；群演不参与轴线计算但行动方向感一致
- 群演表情降级：远景群演只需姿态符合氛围

### 3. 运动方向与出入画
- **出入画方向匹配**：出画左 → 下一镜从画右入画；违反即空间跳变
- **行进方向锁定**：走路/追逐全程屏幕方向锁定，换向必有转弯镜头或中性镜头过渡
- 入画=登场、出画=离场留空；段落有出入画必须在轴线栏记录方向供下段承接

### 4. 视线匹配、POV与机位高度
- **视线匹配剪辑**：人物看向画外某物 → 下一镜接所看对象（POV或客观插入），**对象空间方位与视线方向一致**
- **POV规范**：POV前必须先有"看的人"镜头建立；POV内不出现看者；POV后通常回接反应
- POV是特写禁令的合法补充（看信/看手机/看伤口/看远处来人）
- **机位高度=视线高度**：对话戏机位默认取人物眼高；俯仰偏离必须是权力关系表达（俯拍=压制、仰拍=威压）
- **权力反转律（v2.2新增）**：局势瞬间逆转（如救兵降临碾压反派）时，仰俯角必须在下一镜**同步反转**——原被俯拍的转为仰拍，原被仰拍的转为俯拍

### 5. 位置锁定规则
- **所有人位置锁定**：每段站位与上段末尾完全一致；位置变化必须有剧本动作支撑
- 走位必须精确写出新位置，下段首帧与空间关系栏精确承接；**后退半步也算位置变动**
- 低位起身后必须精确写出站起后位置，后续严格连续承接

### 6. 站位描述要素 ⚠️ v2.2扩展（六要素→九要素）
每段必须写清：
1. 横向：左侧 / 中间 / 右侧
2. 纵深：前景 / 后景
3. 中轴关系
4. **高低关系（v2.2新增）**：站/跪/坐/倒地/高台/楼上楼下/空中——谁在高位谁在低位
5. **绝对距离（v2.2新增）**：双方相隔约X米/X步（贴身0-1米/中距2-5米/远距10米以上）
6. **遮挡关系（v2.2新增）**：谁被门框/栏杆/人群/烟尘等部分遮挡（无则写"无遮挡"）
**不允许写"同上站位"、"站位不变"**

### 7. 空间真实性原则 ⚠️ v2.2新增
- **严禁为了台词更清楚、表情更好读、画面更"好看"，擅自压缩真实距离、抹平高低差、改变遮挡关系，或把远处/高位/背景层目标拉入前景**
- 使用特写/长焦/浅景深时，必须补写一句空间确认（"XX仍在远处高台上，未靠近"）防止模型误判位置
- **垂直交互重载（v2.2新增）**：发生压制、悬吊、踩踏、背负、抓举等零距离垂直接触时，空间描述必须改写为**受力点相对关系**（"从上方死死扣住""在下方被绝对压制"），**禁用"同层/同一平面"表述**；体型悬殊交互（人与巨物）时，小体型方的空间参考锚定在巨物的**具体接触部位**（爪/掌/肩）而非巨物中心

### 8. 视线关系位 ⚠️ v2.2扩展
每段必须写：
- 角色A看向谁、角色B看向谁、是否对视、视线是否对上（与轴线方向一致）
- **游离视线落点（v2.2新增）**：回避/心虚/傲慢/沉思等不对视情形，必须声明视线**具体落点**（如"视线垂向右下方地面""望向画左窗外远处"），不得只写"不看对方"
- **高低差对视（v2.2新增）**：双方存在高低差时强制标注**仰视/俯视**（低位者仰视高位者，反之俯视）
- **视线跟随（v2.2新增）**：被注视目标移动时，注视者声明"头部与目光伴随目标移动"

### 9. 动势衔接规则 ⚠️
- 姿态变化必有过渡过程（坐→站写"撑桌起身"），禁止跳变；变化前有动势铺垫
- **前后段动势丝滑衔接**：下段首帧姿态/动作方向/朝向严格承接上段末帧
- **自检**：写完每段回顾上段末帧，确认匹配无割裂

## 四、人物与环境状态、表演

每段必须补：实际出场人物（含造型ID）/ 人物特殊道具（哪只手）/ 姿态状态 / 情绪状态（动作服务情绪）

### 站桩禁止与反应分级 ⚠️
- **绝对不允许站桩式念台词**；说台词必须伴随手部动作和表情变化，台词挂在动作和情绪上
- **入镜必有反应**——颗粒度按景别分级（见第五章粒度分级）：特写/近景=微表情，中景=眉眼轮廓+肢体，远景=宏观肢体势态
- **焦外角色休眠（v2.2新增）**：在场但非焦点的角色（背景深处/焦外/旁观位），每镜保留**一句宏观行为锚点**做空间占位（如"画右后景XX保持持剑戒备"），**严禁拆解其五官表情**——既防背景崩坏又省字数
- 避免死脸：旁观者表情与场景氛围一致（群演按降级规则）

### 表情过程化规则 ⚠️ v2.2新增
- **表情必须写成变化过程，不是静态结果**：优先用"先……随后……说到某词时……说完后……"的过程结构
- **必须绑定触发点**：表情变化由具体事件触发（听见某句话/看见某动作/意识到某事实/强忍情绪）
- **禁止抽象情绪标签**："愤怒地""震惊地"等括号式提示不得替代表情描写，必须落到具体生理细节（眉峰/瞳孔/鼻翼/嘴角/咬肌/喉结/手指）
- 描写粒度严格服从景别分级（远景禁器官级细节）；字数预算紧张时优先保过程结构、删形容词

### 人物外观状态连续性 ⚠️
- 湿身、出汗、流血、泪痕、泥污、破损等状态从发生起**全程保持**，直到剧本明确消除动作
- 每段道具姿态栏复述持续中的外观状态

### 环境与道具状态连续性 ⚠️
- 雨雪、烛火、翻倒桌椅、碎裂花瓶、洒落水渍等环境状态同样全程连续，每段场景栏复述
- **道具交接**：拿起/放下/递接尽量单镜头内完成；跨镜则两侧严格标注道具位置与持有手
- 杯中水位、信纸折痕等关键道具微状态同样追踪

### 情绪衔接规则 ⚠️
- 同场次情绪全程连贯递进，转折必须有剧本支撑；旁观者情绪与场景一致
- **前后段情绪丝滑衔接**：下段首帧严格承接上段末帧情绪落点；**过渡必有载体**（台词/动作/表情/呼吸）

## 五、节奏、负载与景别

### 1. 负载分级 ⚠️ v2.2新增（绑定镜头时长）
每段在规划表与段落标记中判定负载等级：

| 负载等级 | 触发条件 | 单镜时长 | 策略 |
|----------|----------|----------|------|
| 极高负载 | 近身肉搏接触 / 3人以上同框 / 复杂特效巨变 / 复杂环境大全景 | **0.5-2秒** | 高频急切掩盖穿模（动作豁免段内） |
| 中负载（默认） | 2人对峙 / 带位移交互 / 常规对话 | **2-4秒** | 丹姐默认节奏 |
| 低负载 | 单人静止情绪戏 / 空镜 / 极简对话 | 2-4秒，**情绪长镜可放宽至6秒** | 长镜呼吸感，禁止凑时长 |

- 段时长上限15秒不变（超长台词段18秒）；反应/插入镜头1-2秒例外照旧
- 负载越高切镜越密——**高频切镜是掩盖AI物理穿模的主动手段**，不是节奏失控

### 2. 时间约束与时长核算 ⚠️ v2.2强化
- 段时长参考梯度：1句台词→4-6秒2-3镜 / 2句→6-8秒3-4镜 / 3-4句→10-12秒4-5镜 / 台词多→12-15秒5镜 / 动作豁免段→6-15秒2-8镜
- **时长双轨核算（v2.2新增）**：单镜时长 = **MAX(台词时长, 动作时长, 运镜时长, 特效时长)**（并行发生时）；动作有先后因果则**串行累加**；禁止凭感觉估算
- **动作真空期补帧（v2.2新增，反站桩核心）**：当镜头时长由台词决定而动作提前做完（说8秒话、动作2秒完），**真空期必须用待机微动作填满**——持械警戒、胸口起伏、眼神游移、手指摩挲、汗水滑落；**提示词中禁止留动作真空**
- **时间轴核算**：分秒区间首尾相接、无重叠无空洞、总和=段时长、台词秒数与字数换算相符（4-5字/秒）
- **⚠️ 核算显式输出义务（v2.3新增，实测防偷懒闸门）**：每段必须随稿输出紧凑【时长核算表】，逐镜列出计算式——台词字数÷语速、动作链各项耗时、并行取MAX或串行累加的取值依据；**只给时间码不给推演过程=自检不合格，不得出稿**
  - 语速基准：常速4.5字/秒、爆发喊话5字/秒、虚弱/哽咽3.5字/秒；句首情绪前摇0.3-0.5秒
  - 动作基准：瞬发动作0.5-1秒、常规交互1.5-2.5秒、慢速细节3-5秒、常速步行约1.3米/秒
  - **切镜省略原则**：位移与过程的中段可用切镜省略（电影时间压缩的唯一合法手段）；但**单个镜头内部的时间必须物理真实**，不得把串行动作压进装不下的秒数
  - 说话与互斥动作（呲牙/咬牙/喝水等占用口部的动作）不得并行，必须串行累加
- 禁止长镜头：连续相同运动运镜=视觉长镜头，必须避免

### 3. 景别规范 ⚠️
- 常规景别：全景 / 中景 / 中近景 / 近景
- **说话期间禁止胸部以上特写（对口型规避）——硬规则**（情绪贴脸用"听者特写+画外台词"方案）
- **条件许可面部特写**：非说话时刻 + 有定妆锚点（参考图或文字定妆）+ 情绪爆点，三条同时满足 → 允许，每段≤1个，1-2秒
- 无定妆锚点角色：维持禁特写
- 眼睛/嘴巴大特写：高风险选项，仅强参考图+情绪顶点时使用

### 4. 景别-细节粒度分级 ⚠️ v2.2核心新增（光学可见度法则）
**描写粒度必须匹配景别的物理可见度，严禁跨尺度描写：**

| 景别（物理距离） | 表情粒度 | 物理细节粒度 | 台词处理 |
|------|----------|----------|----------|
| 远景/全景（>5米） | **禁器官级微表情**——强制宏观肢体势态（躯干紧绷/踉跄后退/身形戒备/阵型变化） | 环境级（地形塌陷/气浪扩散/建筑倒塌/天色突变） | 不写口型喉结——"伴随远处的怒吼声（台词），人物挥臂（宏观动作）" |
| 中景/中近景（2-5米） | 眉眼轮廓+大致嘴型变化，禁瞳孔/毛孔级 | 中观级（衣摆撕裂/碎石飞溅/武器相撞光晕） | 常规出镜说话（最小近景规则照旧） |
| 近景/特写（0-1米） | 全量微表情（瞳孔/咬肌/喉结/汗珠） | 微观级（血丝/火星/尘粒/布料纹理） | 出镜说话或听者特写+画外 |

- 这同时是**字数预算优化器**：远景省下的微表情字数投给动作与空间
- "入镜必有反应"的判定随分级执行（见仲裁表）

### 5. 空镜规范（B-Roll）⚠️ v2.2新增
- **定义**：无人物出现的纯环境/物体镜头（空镜≠全景——全景有人物站位，空镜没有；空镜不受全景规则约束，**可承载画外台词与环境音**）
- **三大用法**：①开场氛围铺垫 ②**剧烈情绪爆发后的缓冲**（争吵/哭喊/重击后插2-3秒空镜沉降）③结尾留白余韵 / 暗示时间流逝（天色变化）
- 时长2-4秒，必须有动势（光影移动/风吹/雨落/烛火摇曳）
- 段总时长<10秒可省略；情绪爆发段建议必配

### 6. 焦段表

| 景别 | 推荐焦段 | 说明 |
|------|----------|------|
| 全景/定位帧/空镜 | 24-35mm | 空间交代 |
| 中景 | 35-50mm | 调度主力 |
| 中近景 | 50-85mm | 对话主力 |
| 近景 | 85mm | 压缩背景、浅景深 |
| 面部特写（条件许可） | 85-105mm | 必须背景虚化 |

- 广角贴近人物产生畸变，仅用于压迫/眩晕/失衡的刻意表现

### 7. 景别丰富度
- 必须多景别，避免连续相同景别；变化有逻辑并遵守30°规则

## 六、镜头与运镜 ⚠️ 核心章节

### 1. 切镜规则 ⚠️
- **切镜头直接切，绝不用运镜切换**；运镜仅作用于单镜头内部
- 禁止：❌甩镜切 ❌推进切 ❌拉远切 ❌平移切
- **切点选择**：跨条生成慎用"动作中切"，优先**动作完成点**或**反应点**切；同条生成内可用动作顶点切（动切动）；**肢体接触类动作强制用"接触前切出→受击结果"**（见反穿模条款）
- 场次间默认直接切；匹配剪辑建议写后期备注

### 2. 一镜到底段 ⚠️ v2.2新增（用户声明触发，慎用）
- 用户明确要求"一镜到底/连续调度"时，该段标注【一镜到底段】：
  - **豁免切镜规则与单镜时长限制**——段内不切镜，用连续运镜组合调度（推进转摇上、平移转推进、跟拍穿梭等）
  - 段时长≤单次生成上限（默认15秒）；轴线、状态连续、台词规则、禁用词照常生效
  - ⚠️ 漂移风险高：避免复杂多人交互与肢体接触，优先单人/双人简单调度场景
- 未声明时一律按默认切镜逻辑执行

### 3. 动势原则 ⚠️
- **每镜必须有动势**——镜头运动或画内主体运动至少其一
- **定镜许可**：定镜+明显画内动势=合法（对峙僵持/权威/压迫/惊愕定格/正反打对切）；全篇≤30%、对话段≤50%
- **绝对禁止：定镜+人物静止无表演=冻结帧**（真空期补帧规则同时兜底）

### 4. 运镜分级
- **主选**：左右平移 / 缓慢推进 / 拉远 / 定镜+画内动势
- **辅助**：旋转摇上、旋转摇下（每段≤1次、≤匀速、留给情绪转折）、升降、半环绕、跟拍、急推/急拉、纵深推进、低角度、俯拍
- **慎用**：全环绕；**禁止**：甩镜
- **多样性**：连续两镜不得相同运动运镜（正反打定镜对切豁免）；单一方式参考上限40%；运镜以"表达什么"为准，禁机械轮换

### 5. 运镜术语表（统一用词）
| 术语 | 定义 |
|------|------|
| 推进 | 镜头向前推近，聚焦人物上半身/手部/关键道具 |
| 拉远 | 镜头向后拉开，露出更完整空间 |
| 升镜/降镜 | 镜头垂直缓慢上升/下降 |
| 旋转摇上 | 从低位边缓慢旋转边向上摇起（情绪升华/觉醒/登场） |
| 旋转摇下 | 从高位边缓慢旋转边向下摇落（情绪沉落/压迫递增） |
| 左/右平移 | 画面匀速水平横移 |
| 斜向滑动 | 沿斜上/斜下角顺滑滑动 |
| 半环绕 | 围绕人物缓慢环绕约30° |
| 全环绕 | 360°环绕（AI极易崩，慎用） |
| 跟随跟拍 | 贴身跟随人物移动 |
| 侧面跟拍 | 侧面平行跟随 |
| 纵深推进 | 沿通道/纵深线向前推进 |
| 低角度贴地 | 贴地面低角度拍摄 |
| 俯拍 | 高位向下俯拍/上帝视角 |
| 组合运镜 | 推进转摇上、拉远转升镜、平移转推进等（一镜到底段主力） |
| 氛围运镜 | 前景遮挡推进、逆光勾边推进、雾中推进 |
| 穿梭运镜 | 穿窗镜头、回廊穿梭 |

### 6. 运镜配合情绪与台词 ⚠️ v2.2强化
- 情绪递进→运镜加速或推进；沉落→放缓或拉远；台词节奏与运镜速度匹配
- **镜头语言对照**：推进=压迫聚焦 / 拉远=疏离释然 / 升镜=升华 / 降镜=沉重 / 平移=流动 / 急推急拉=爆发 / 定镜=凝滞威压 / 入画=登场 / 出画=离场留空
- **蓄水与破堤（v2.2新增）**：核心冲突爆发前用长镜/定镜拉出"死寂稳态"蓄压；爆发瞬间**零预警直接切**入急切短镜（极高负载0.5-2秒碎切），禁止任何转场铺垫——前一秒极静、后一秒极动
- **降维压迫（v2.2新增）**：单方面力量碾压时放弃均势对打剪辑——**强者用极静的长镜/定镜，弱者用极动的挣扎碎切**，以静衬强
- **长短阵型声明（v2.2新增）**：每段分秒运镜前标注节奏阵型（如"长-短-极短-长"），用镜头长短的排列外化情绪律动，禁止均质平分时长
- 每个运镜选择必须能回答"这个运镜在表达什么"

### 7. 运镜场景对照表

| 剧情场景 | 推荐运镜 | 速度 |
|----------|----------|------|
| 交代环境/空间关系 | 全景缓推、俯拍、升镜拉远 | 缓慢 |
| 氛围铺垫/情绪酝酿 | 缓慢推进、左右平移、定镜+画内动势 | 缓慢 |
| 紧张对峙/冲突升级 | 定镜凝滞（蓄水）、推进、平移 | 匀速至快速 |
| 动作场面/情绪爆发 | 跟拍、急推、碎切（破堤）、环绕（豁免段） | 快速 |
| 对话交流 | 单人正反打+微平移或定镜、缓慢推进、反应镜头 | 匀速 |
| 高潮/逆转 | 急推、急拉、旋转摇上（每段≤1次）、仰俯反转 | 快速 |
| 结尾收束/留白 | 缓慢拉远、定镜+画内动势、空镜 | 缓慢 |
| 单人独白/内心戏 | 缓慢推进、微平移、定镜 | 缓慢 |
| 人物出场 | 推进、纵深推进、低角度、入画 | 匀速 |
| 力量碾压 | 强者极静长镜 vs 弱者极动碎切 | 对比 |

### 8. 运镜速度标注
格式：`运镜方式（速度）`——缓慢/匀速/快速；旋转类≤匀速
- **速度与时长匹配**：缓慢运镜需≥3秒镜头；0.5-2秒短镜只配微动、定镜或急推急拉

### 9. 气口与声桥 ⚠️
- **留1秒气口**：最后一句台词后留≥1秒画面延续，不卡尾帧
- 声桥提示（可选后期备注）：J-cut / L-cut

### 10. 每条运镜必须包含
景别（焦段）/ 运镜方式（速度）/ 构图 / 镜头语言（表达什么）/ 表情情绪（按景别粒度）/ 动作 / 屏幕方向与视线 / 台词呈现方式（出镜·画外·OS·无台词）/ 空间关系（含高低与距离）/ [光效]

### 11. 构图类型（按画幅适配）
- 竖屏主力：纵深引导线、前景压边、高低位压迫、中心压迫、人物偏置、上下分层
- 横屏补充：对角线、三分法、左右对峙、过肩
- 镜面/水面反射构图慎用（AI反射易崩），确需时虚化或只取局部

## 七、全景与站位定位帧

### 1. 全景禁台词 ⚠️ 绝对规则
- 全景/定位帧中不允许任何角色说话、OS、VO、画外台词——所有人声通道静默（环境音除外）
- 台词未说完先完成台词再出全景
- （空镜≠全景：空镜无人物，可承载画外台词，见第五章）

### 2. 新场景全景开场
- 新场景首次出现必须全景开场（集首段钩子帧例外：钩子先行、全景随后）
- **多人全景崩脸缓释**：背影机位/高机位俯拍/剪影/拉开距离，避免多人正脸全景

### 3. 站位定位帧 ⚠️
- 叙事结尾镜头**之后的附加帧**，≤2秒，无台词，轻微运镜或画内动势
- 触发：①第一段结尾 ②位置/姿态/方向变化的段末 ③无变化不出
- 豁免：集尾段；性质：不算结尾镜头、不参与首帧换人判断；同样适用崩脸缓释

### 4. 推进剧情的全景
- 展示走动/位移过程（追逐/入场/离场）时允许，**必须搭配运镜**，纯静止全景不得推进剧情

## 八、首帧与结尾镜头

### 1. 首帧优先级（取第一个命中项）
1. **集首段** → 钩子帧（承接上集末状态快照）
2. **新场景段** → 全景开场（含崩脸缓释）
3. **同场景延续段** → 换人：上段叙事结尾镜头人物**以外**的角色
4. **单人戏** → 道具/手部/背影/环境局部替代
- 首帧即图生视频种子帧，必须精确（人物、姿态、屏幕方向、景别、光效）

### 2. 结尾镜头规则
- **叙事结尾镜头禁全景**；可以是中景/中近景/近景/道具/反应/环境局部/空镜
- 服务下段承接；下段首帧不得从该人物开始（同场景延续时）
- 集尾段：结尾镜头=悬念帧

## 九、反应镜头与台词上镜策略

### 1. 反应镜头规则
- 人物说话时必须给其他重要角色反应镜头；重点情绪台词处必须给反应
- 入镜必有反应（粒度按景别分级）；反应镜头近景/中近景为主，1-2秒，配运镜或画内动势
- 所有人说话不正对镜头；可正面、侧面、背面拍摄

### 2. 台词上镜策略 ⚠️（对口型风险管理核心）
每句台词标注呈现方式：
- **出镜说话**：说话者画内开口（需对口型）——最小近景；重要情绪台词、宣言、对峙台词优先出镜
- **画外台词**：说话者暂不在画内，台词压在**听者反应镜头/空间镜头/空镜**上——完全规避对口型；信息过渡型台词优先画外
- **内心OS（v2.2新增，开关默认关）**：用户声明启用后合法。规则：
  - 标注格式：[角色X-内心OS]；属于角色当下内心声音，**≠解说旁白**（旁白仍永禁，三态判定见仲裁表）
  - **双轨绑定强制**：OS响起时画面必须有该角色对应的生理反应/微表情/小动作（如瞳孔骤缩、指尖收紧）——禁止OS悬浮在无反应的画面上
  - OS无对口型风险，可压在本人任意景别镜头上（全景/定位帧除外）；OS计入台词字数统计
  - 适用场景提示：重生/穿越/复仇文的内心吐槽与心理反转是叙事利器，但密度过高会稀释表演——建议每段≤2句
- **无台词**：纯反应/动作/定位/空镜
- **画外台词+OS合计占比≤50%**；爆点台词必须出镜说
- "听者特写+画外台词"=情绪贴脸时刻的合法组合
- 全景/定位帧禁一切人声（含画外与OS）

## 十、集级结构与跨集管理

分镜层的钩子责任=**选帧**：开场选最强画面、结尾选最吊画面。
- **集时长预算**：单集60-120秒≈5-8段，规划表先行分配
- **集首段**：第一镜=钩子帧，允许冷开场（钩子先行、全景随后）
- **集尾段**：结尾镜头=悬念帧；禁全景、豁免定位帧
- **付费卡点**：按集尾段标准执行
- **集末状态快照**：各角色位置/姿态/情绪/外观/造型ID+场景环境状态，供下集承接
- 未分集时按单集处理

## 十一、光效与打光

### 1. 打光决策顺序 ⚠️
**第一步：光源动机**——查场景表主光源清单，主光方向/性质必须能被场景内光源解释，提示词写明光从哪来
**第二步：情绪反差**——冲突=硬光高反差 / 温情=柔光低反差 / 审判压抑=顶光 / 恐惧=低位光 / 悬疑=侧光分割
**第三步：缺省方案**（无明确依据时）——男性=侧光塑形（写"面部一侧受光、另一侧渐变阴影"，⚠️不写"三角光斑"）；女性=柔和顶前光（写"正面柔光、面部立体柔美"）；悲情/惊悚戏按情绪反差打光，不得机械套用美颜光
**第四步：轮廓光**——近景/中近景/氛围镜头默认侧逆光勾边，前提是存在可解释背光源；不成立改用色彩分离/景深分离
**第五步：阴影补光自检（v2.2新增）**——人物处于背光/阴影/俯卧位而剧情需要面部可读时，提示词必须补"环境漫反射补光/微弱辅助底光"，符合曝光逻辑，禁止阴影里凭空清晰

### 2. 光位锁定 ⚠️
- 主光方向同场次锁定（窗在画左则全场主光从画左来），正反打两侧受光面服从同一光源逻辑
- 光位变化必须有剧情支撑（开灯/熄烛/日落），变化后重新锁定并标注

### 3. 色温规则
- 同场次色温统一；场次间转变走过渡段；逆光色温与主光一致

## 十三、声音与特效

### 1. 特效提示词
- 特效服务剧情，与动作、环境反馈、镜头同步，写成可视化内容；粒度遵守景别分级（远景写环境级、特写写微观级）

### 2. 音效建议（与运镜联动）

## 十六、执行口诀（丹姐6月 v2.2版）

**总纲**：三层分明，冲突看仲裁表；流程六步——读本→资产表→规划表→逐段产出→分级自检→交付含快照

**开工**：定画幅（默认9:16+安全区）、建资产表（造型/时段变体+文字定妆锚点+光源清单+全局开关）、出规划表（含负载判定与集时长预算）

**拆段**：四断点优先（时空跃迁/微目标转换/阵营变动/情绪沉降），200字辅助；不漏不删台词；回忆与长动作禁梗概化；每15秒20-45字；超长单句走仲裁

**负载**：极高负载0.5-2秒急切掩穿模、中负载2-4秒、低负载情绪镜可至6秒；时长=MAX(台词,动作,运镜,特效)或串行累加；**真空期必补待机微动作**；**每段强制附时长核算表显示计算过程（只给时间码=不合格）**；说话与占口动作必须串行；镜头内时间物理真实、压缩只能靠切镜省略

**轴线**：每场建轴锁一侧；每镜标画左画右与面朝；越轴走过渡；多人主轴+区域固定；30°防跳剪

**方向**：出画左入画右；行进方向锁定；视线匹配（看→所看方向一致）；POV先建立看者；游离视线声明落点；高低差标仰俯；权力反转时仰俯角同步反转

**空间**：站位九要素（横向/纵深/中轴/高低/距离/遮挡）；严禁为台词清晰或构图好看篡改真实距离与高低差；垂直交互写受力点关系禁"同层"；特写补空间确认句

**粒度**：细节描写匹配景别——远景宏观势态禁微表情、中景眉眼轮廓、特写全量微观；远景台词不写口型；焦外角色一句宏观锚点占位

**表情**：过程化（先…随后…说完后…）+触发点绑定，禁抽象标签；按景别分级

**状态**：人物外观+环境道具双线连续；道具交接单镜完成；造型同场锁定

**衔接**：姿态变化有过渡；前后段动势/情绪丝滑承接

**切镜**：直接切；运镜只在镜头内；肢体接触=接触前切出→受击结果+遮挡借位；跨条慎用动作中切；一镜到底段（用户声明）豁免切镜、慎用

**镜头动势**：每镜必有动势；定镜+画内动势合法（≤30%、对话段≤50%）；旋转摇每段≤1次；缓慢运镜≥3秒

**节奏**：长短阵型外化情绪，禁均质平分；蓄水（长镜死寂）与破堤（零预警碎切）；力量碾压用强者极静vs弱者极动；大场面≥30%镜头给涟漪（环境反馈/旁观反应）

**景别**：说话禁胸上特写；非说话+定妆锚点+爆点=条件特写；情绪贴脸用听者特写+画外台词

**台词上镜**：每句标出镜/画外/OS/无台词；画外+OS≤50%；爆点出镜；OS默认关、启用后必须双轨绑定微表情（≠旁白，旁白永禁）

**全景**：禁一切人声；新场景全景开场（集首让位钩子）；多人全景缓释；≤2秒有动势；空镜≠全景（可载画外台词，爆发后2-3秒缓冲）

**定位帧**：叙事结尾后附加；首段结尾与变化段末触发；集尾豁免

**首帧/结尾**：钩子帧>新场景全景>换人>单人替代；叙事结尾禁全景；集尾悬念帧；集末出快照

**打光**：光源动机→情绪反差→性别缺省；光位同场锁定；阴影面部补漫反射；近景勾边须光源成立；色温按题材统一

**闪回**：单独成段+统一编码+三明治闭环（切回衔接情绪突变）+分型时长（闪现1-2秒/叙事多镜）+禁跨批次截断

**高危回避**：文字道具虚焦+画外读出；镜面慎用；密集手部简化；肢体接触反穿模；多人正脸缓释

**音效**：与运镜联动；爆点三件套——静音真空（前0.5秒抽空）+重音卡点（切入砸下）+听觉反差

**禁用词**：眼神光/面部光斑/临时外貌词/具体文字/BGM/旁白/抽象字段名永不写；文字定妆词组是外貌词唯一例外（逐字复用）

**字数**：1900字只计提示词正文；粒度分级省字反哺动作与空间

**自检**：先🔴阻断14条，再🟡质量30条
